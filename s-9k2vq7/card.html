① 청구병합의 허용 여부 — 같은 종류의 소송절차파노2 병합 1~4

✓ 가압류·가처분 이의사건과 본안 민사사건은 다른 종류의 소송절차 → 변론병합 불가(2001다23225). ✓ 이혼·재산분할(가사) + 부부간 명의신탁해지 이전등기(민사) 병합 불가(2004므1378). ✓ 재심의 소에 통상 민사청구(등기말소) 병합 불가(71다8). ✓ 제권판결 불복의 소에 다른 민사청구 병합은 원칙 불가(2012다36661)이나, 제권판결 과정의 불법행위 손해배상은 병합 가능(88다카7962). ✓ 허용 예: 행정소송 + 관련 민사청구(행소법 제10조).

② 병합 형태 판단 기준 — 당사자 의사 ✗, 청구의 성질 ✓파노2 병합 5~10

✓ 선택적이냐 예비적이냐는 "당사자의 의사가 아닌 병합청구의 성질을 기준"(2013다26425, 2013다96868). ✓ 선택적 = 양립 가능한 수개 청구, 어느 하나 인용을 해제조건 / 논리적으로 양립 불가한 청구는 선택적 병합 불가(81다카1120). ✓ 행정처분 무효확인 + 취소 = 예비적(70누123). ✓ 원인무효 말소 + 명의신탁해지 이전등기 = 예비적 → 말소청구부터 판단. ✓ 주위적 청구를 양적·질적으로 일부 감축한 청구는 주위적에 흡수될 뿐 예비적 청구 아님(2016다225353, 98다61463).

③ 대상청구(본래 급부 + 전보배상) = 단순병합파노2 병합 11~13

✓ 이전등기·인도청구 + 판결확정 전 이행불능·확정 후 집행불능에 대비한 전보배상 = "현재의 급부청구와 장래의 급부청구의 단순병합"(2005다55411, 대판 2011.1.27.). ✓ 이를 예비적으로 붙였더라도 "본래의 급부청구가 인용된다는 이유만으로 예비적 청구에 대한 판단을 생략할 수는 없다"(2011다30666). ✓ 주위적 청구원인이 이유 있으나 항변으로 일부 기각 → 원칙상 그 부분 예비적 청구원인 판단 불요(99다53742). 다만 일부 특정 예비적 청구 취지면 추가 심리(94다50274).

④ 선택적 병합과 상소 — 항소기각 ✗, 1심 취소 후 인용파노2 병합 14~16 · 41~42

✓ 1심이 하나를 인용 → 피고 항소 → 항소심은 심판 순서 제한 없음, 판단 안 된 청구를 임의로 선택 가능. ✓ 그 청구가 이유 있고 결론이 1심 주문과 같아도 항소기각 ✗ → "제1심판결을 취소한 다음 새로이 청구를 인용"(92다7023, 2006다7587). 항소심에서 선택적 추가 청구를 먼저 인용할 때도 같음. ✓ 선택적 청구를 모두 기각한 원심에 원고 상고 → 하나라도 이유 있으면 원심판결 전부 파기(2006다79995, 2015다42599) — 성질상 선택적 청구에 순위를 붙인 경우도 같음(2017다247145).

⑤ 예비적 병합과 상소 — 이심 범위 vs 심판 범위파노2 병합 7 · 17~20

✓ 주위적 판단 없이 예비적만 인용하거나 주위적만 배척하고 예비적 미판단 = 성질에 반하는 일부판결로 불허(2020다292411). ✓ 주위적 일부인용·예비적 기각 → 피고 항소로 주위적 일부 기각 시 관련 예비적도 심판(98다22253 전합). ✓ 주위 기각·예비 인용에 피고만 항소 → 전부 이심(상소불가분)되나 심판범위는 예비적 부분뿐, 원고 부대항소 없으면 주위적 심판 ✗(94다31624). 같은 결론 유지 후 원고 상고 → 상고이익 없어 각하(94다29065). ✓ 피고가 항소심에서 주위적 청구 인낙 → 예비적은 심판 없이 종결(92다12032).

⑥ 부진정 예비적 병합파노2 병합 21~26

✓ 단순병합할 청구를 예비적으로 병합 = 부적법. 1심이 일부만 판단하고 나머지 생략 → 병합형태가 예비적으로 바뀌지 않고, 미판단 청구는 1심에 계속(2009다10898). ✓ 단순병합 청구를 선택·예비로 구해 하나 인용·나머지 기각 → 피고 항소 시 전부 이심되나 심판범위는 피고가 불복한 청구(2005다51471). ✓ 양립 가능한 청구라도 "순위를 붙여 청구할 합리적 필요성"이 있으면 그 순서대로 심리(2001다17633, 2020다292411). 주위적 일부 기각 시 예비적 판단 여부를 석명(98다17145). 미판단 예비적도 상소심으로 이심.

⑦ 청구변경 요건 — 청구기초 동일성은 사익적파노2 병합 27~33

✓ 담보가등기 본등기청구에서 피담보채권 주장(대여금→손해배상) 변경 = 공격방법일 뿐 청구변경 ✗(92다11848). ✓ 청구기초 동일성 = 사익적 요건 → 이의 없이 본안변론하면 다툴 수 없음(2009다33655). ✓ 교환적·추가적·선택적 불분명 → 사실심 석명의무(2007다51703). 신청구가 부적법하면 구청구 취하되는 교환적 변경으로 볼 수 없음(73다1449). ✓ 공법상 당사자소송 → 민사소송 변경 허용(대판 2023.6.29.). ✓ 청구취지 변경은 서면(제262조 제2항), 청구원인 변경은 구두 가능 / 서면 아닌 변경도 이의 없으면 치유(82다카262). ✓ 변경 불허 결정 → 독립 항고 ✗, 종국판결 상소로(92누5096).

⑧ 교환적 변경의 간과·항소심 교환적 변경파노2 병합 34~38

✓ 1심이 교환적 변경을 간과하고 구청구만 판단 → 항소심은 1심판결 취소 + 구청구 소송종료선언, 신청구는 재판누락 → 1심 추가판결(2002다56987). ✓ 항소심 교환적 변경 → 1심판결은 소취하로 실효, 항소심은 "사실상 제1심으로서" 신청구 판단 / 판단 누락 시 원심에 계속(2016다45595). ✓ 그 뒤 피고 항소취하는 대상이 없어 무효(93다25875). ✓ 신청구 기각 시 주문은 "원고의 청구를 기각"(항소기각 ✗)(73다1796, 96다25449). ✓ 항소심 예비적 청구 추가 — 피고 동의 불요(청구기초 동일성으로 심급이익 보호).

⑨ 항소심 청구 추가와 주문파노2 병합 39~40 · 43~45

✓ 원고 패소 후 항소심에서 예비적 청구 추가 → 주위적 항소가 이유 없으면 예비적은 제1심으로서 판단(2016다253297). ✓ 기존·추가 청구 모두 배척 → "항소기각 + 추가청구 기각"(2004다24083, 2020다292411). ✓ 이유에서만 배척하고 주문에 "항소기각"만 → 추가청구(단순병합)는 재판누락, 누락 여부는 주문 기재로만 판단(2004다43824) → 원심 계속·추가판결(제212조), 상고는 부적법. ✓ 전부승소 원고가 부대항소로 확장·추가 → 전부 인용 시 "항소기각 + 새 청구 인용" 또는 "원판결 변경".

⑩ 반소의 요건 — 당사자·소의 이익파노2 병합 46~49 · 58 · 62~63

✓ 독립당사자참가인을 상대로 원·피고가 반소 가능(68다656). ✓ 제3자를 추가한 반소는 원칙 ✗, 다만 필수적 공동소송이면 제68조 요건 갖춰 허용(2014다235042). ✓ 이행청구 본소에 같은 채권 채무부존재확인 반소 = 부적법(본소 기각 구하는 것 이상 없음)(2005다40709). ✓ 반대로 채무부존재확인 본소 뒤 이행 반소가 와도 본소 확인이익 유지(2010다2428). ✓ 상호관련성 = 사익적 요건(68다1886). ✓ 점유의 소 본소 + 소유권 반소 가능, 둘 다 인용(2019다202795). ✓ 사해행위취소 반소 인용 시 미확정이어도 이를 전제로 본소 기각 가능(대판 2019.3.14.).

⑪ 항소심 반소 — 제412조파노2 병합 51~53 · 55~56 · 64

✓ 항소심 반소는 상대방 심급이익을 해할 우려가 없거나 동의 시(제412조 제1항). 이의 없이 반소 본안 변론 = 동의 간주(같은 조 제2항). 그러나 "반소기각 답변"만으로는 동의로 볼 수 없음(91다1783). ✓ 추완항소하며 반소 → 추완항소 각하되면 반소도 소멸(2003다16962). ✓ 1심 반소를 항소심에서 교환적 변경 — 청구기초 동일하면 허용(2010다28338). ✓ 예비적 반소 추가는 반소피고 동의 불요(68다1094, 93므1051). ✓ 공시송달 판결로 이전등기 후 추완항소로 1심 취소 → 그 절차에서 반소로 말소청구 가능(2021다276225).

⑫ 예비적 반소와 반소 취하파노2 병합 50 · 54 · 57 · 59~61 · 65

✓ 단순반소는 본소 취하돼도 영향 ✗, 예비적 반소는 본소 취하·각하 시 효력 상실(69다446). ✓ 본소 인용 조건 예비적 반소 → 본소 기각되면 반소 판단 불요(소각하 ✗) / 원고만 항소, 항소심이 본소 인용하면 예비적 반소도 심판대상(2006다19061). ✓ 원인채권이 다른 사건 상계항변으로 인용 확정 → 예비적 반소 이익 없음(2010다30966). ✓ 이혼 본소의 재산분할청구 = 반소 이혼 인용 시 재반소 실질 → 재산분할 판단(2001므626). ✓ 본소가 각하된 때는 원고 동의 있어야 반소 취하 — 제271조 유추 ✗(84다카298).

⑬ [간격반복] [공법기록] 처분근거 부존재 · 재량행위 일부취소11/10 25년1모 공기록 첨삭 1-5 (1.5/7) · 1-7 (0/4) · 15일차

✓ 사과편지 작성 징계: "법령상 명문의 규정이 없는 징계처분의 효력을 긍정함에 있어서는 그 처분 내용의 자발적 수용성, 교육적·인격적 측면의 유익성, 헌법적 가치와의 정합성 등을 종합하여 엄격히 해석"(2022두39185) + 초·중등교육법 제18조, 시행령 제31조 제1항 제1호 인용. ✓ 소결: "재량행위의 경우 … 여러 개의 위반행위 중 일부의 위반행위에 대한 처분만이 위법하고 처분 대상의 일부가 특정될 수 있는 경우가 아닌 한 … 일부 취소는 허용되지 않는다"(2013두14726, 2007두18062) → 전부취소.

⑭ [간격반복] [국거] 격지불법행위 준거법 5단계10/21 10모 국거 첨삭 문1-나 (4/20) · 11/18 국거 진도 연계

⑮ [간격반복] [형소] 비약적 상고의 효력 · 국참 불회부 불복10/20 10모 형사사례 첨삭 1-5 (1/10) · 1-4 (1/10)

✓ "제1심 변호인의 항소장이 제1심법원에 제출된 상태에서 피고인의 비약적 상고장이 위 법원에 제출되었으므로 … 비약적 상고의 효력이 없다"(2025도11655) → 대법원은 항소심 법원으로 이송. 제373조 인용 자체는 득점 요소(적용 방향 주의). ✓ 단독관할 사건 국민참여재판 불회부: 재판은 적법, 즉시항고 불가 · 항고 불가 → 상소로 불복(2022도2071 사건).
