🌙 취침 전 복습 카드 2026. 7. 6.(월)

오늘 공부 범위: 허정 형법 암기장 1~39p (범죄론 개관·행위의 주체·부작위범)

진도 多 → 쟁점당 1장씩 9장 + 간격반복 2장

① 성립요건·처벌조건·소추조건 구별 암기장 p26

✓ 성립요건(구성요건·위법성·책임): 객관적 구성요건요소는 고의의 인식대상 → 결여 시 구성요건적 고의 조각. 위법성 결여 시 정당방위 불가, 책임 결여 시 정당방위 가능. ✓ 처벌·소추조건: 고의 인식대상 아님 → 결여돼도 정당방위 가능, 이에 교사·방조 시 (제한적 종속성설) 공범 성립 가능. ✓ 판결: 성립요건 흠결=무죄/처벌조건 흠결=형면제/소추조건 흠결=공소기각.

② 즉시범·상태범·계속범 암기장 p26

✓ 즉시범·상태범: 기수=행위종료시, 공소시효도 기수(행위종료)시 기산, 공범 성립·정당방위도 기수시까지. ✓ 계속범: (기수 후라도) 행위종료시까지 공범 성립·정당방위 가능하고 공소시효도 행위종료시부터 기산. (예: 업무상배임 영업비밀 반출과 공범 성립시기 문제)

③ 법인의 범죄능력 — 배임죄 주체 암기장 p29

✓ 법인은 범죄능력 부정 → 배임죄 주체 X. 법인의 타인 사무는 대표기관의 대표행위로 실현되므로 자연인인 대표기관이 배임죄 주체(대판(全) 82도2595 다수견해). ✓ 여기서 '대표자'는 명칭 불문 법인을 실질적으로 경영·사실상 대표하는 자도 포함(2011도15056).

④ 양벌규정 — 형벌능력·사용인 지위 암기장 p29·30

✓ 법인의 범죄능력을 부정하면서도 처벌규정(양벌규정)이 있으면 법인을 행위자와 함께 처벌해 형벌능력은 긍정(82도2595). ✓ 다단계판매원은 방문판매법상 양벌규정 적용에서 다단계판매업자의 '사용인' 지위(2003도4966).

⑤ 소극적 구성요건표지이론 암기장 p31

✓ 위법성조각사유를 소극적 구성요건표지로 보아 협의의 불법구성요건과 통합 → 총체적 불법구성요건(불법·책임 2단계 범죄체계). ✓ 위법성조각사유 존재 시 구성요건해당성 자체가 부정. ✓ 비판: 처음부터 구성요건에 해당 않는 행위(모기 죽임)와 구성요건 해당하나 위법성 조각되는 행위(살인+정당방위)의 가치 차이를 무시.

⑥ 작위와 부작위의 구별 암기장 p32·33

✓ 작위=금지규범을 적극적으로 위반. 부작위=명령(요구)규범이 요구하는 행위를 부작위(단순 '무위'는 형법상 부작위 X). ✓ 명령규범 전제 구성요건은 부작위로만 실현=진정부작위범(퇴거불응죄), 금지규범 전제 구성요건을 부작위로 실현=부진정부작위범. ✓ 신체적·물리적 작용으로 적극적으로 법익상황을 악화시켰다면 원칙적 작위(작위우선·부작위보충설, 인공호흡기 사건 2002도995).

⑦ 부작위범의 공범 (부·의·교·간) 암기장 p34

✓ 부작위에 의한 방조는 가능, 교사·간접정범은 불가. ✓ 부작위범 사이 공동정범: 다수에게 공통된 의무가 부여되고 공통으로 이행 가능할 때만 성립(2008도89).

⑧ 진정부작위범 암기장 p34

✓ 형법은 진정부작위범의 미수처벌 규정을 둠(예: 퇴거불응죄). ✓ 일정 기간 내 잘못된 상태를 바로잡으라는 행정청 지시를 이행하지 않는 것을 구성요건으로 하는 범죄는 진정부작위범 → 의무이행기간 경과로 기수(93도1731).

⑨ 부진정부작위범 — 작위의무·처벌·정범과 공범 암기장 p34·39

✓ 작위의무 발생근거 [법·법·선·조]=법령·법률행위·선행행위·조리(신의칙·사회상규)(95도2551). ✓ 처벌: 발생 결과에 의해, 작위범과 동일 법정형(제18조). ✓ 정범/공범 구별은 종범설(판례) — 은행지점장이 부하직원 배임을 방지 않으면 업무상배임 방조범(84도1906). [제8회 변시 제2문]

⑩ 상업사용인 — 지배인 vs 부분적 포괄대리권 사용인 간격반복 · 퀴즈 오답

핵심 명제(전부 O): 부분적 포괄대리권 사용인은 '영업주를 대리한 법률행위'가 당연히 포함 · 건설회사 현장소장은 부분적 포괄대리권만 보유 · 새 채무부담(지급보증)은 권한 밖 · 권한남용도 행위는 유효하되 상대방 악의·과실 시 무효(민107① 단서 유추) · 표현지배인(상14) 유추적용 X → 민125 표현대리·민756 사용자책임으로 보호.

⑪ 영조물 설치·관리상 하자 — 피해자 행위 경합 간격반복 · 6모 공법사례 25%

✓ '영조물 설치·관리상의 하자'=영조물이 용도상 통상 갖출 안전성을 결여한 상태(2022다225910). ✓ 자연적 사실·제3자·피해자 행위와 경합해도 하자가 공동원인의 하나인 이상 설치·관리상 하자로 발생한 것(94다32924). ✓ 피해자 과실은 과실상계 사유일 뿐 국가배상법 §5 책임 배제 X.
