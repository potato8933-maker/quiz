① 당사자적격 — 총유재산 소송은 고유필수적 공동소송논점 007 ★★★★★

✓ 총유재산에 관한 소송은 민법 제276조 제1항에 의하여 총유물의 관리·처분권이 구성원 전원에게 귀속되므로 고유필수적 공동소송이다. ✓ 고유필수적 공동소송은 구성원 전원이 당사자가 되지 않으면 당사자적격에 흠이 있어 부적법하므로, 구성원 중 일부가 소를 제기하면 당사자적격 없음 → 소각하. ✓ 함정(판례 변경): 종전에는 총유물의 보존행위에 해당하면 구성원 일부가 소를 제기할 수 있다고 보았으나, 입장을 변경하여 총유의 경우는 공유·합유와 달리 보존행위로도 구성원 일부 명의 소제기를 허용하지 않는다. ✓ 즉 “총유 = 보존행위 예외 없음”으로 굳혀 둘 것.

② 처분권주의 — 질적 동일 · 양적 상한논점 018 · §203 · 선택 '16·'21

✓ 법원은 원고가 신청한 사항에 대하여(질적 동일), 신청의 범위 내에서만(양적 동일) 판단하여야 한다(§203). 상소심에서 발현된 것이 불이익변경금지의 원칙. ✓ 질적 동일 = 소송물. 판례의 구소송물이론상 실체법상 권리마다 소송물이 다르므로, 원고 주장과 다른 실체법상 권리에 기한 판결은 위법(불법행위 청구에 채무불이행 책임 인정 → 처분권주의 위반). ✓ 채무부존재확인 양적 상한: 1,000만 원 중 400만 원 초과 부존재를 구하는데 법원이 200만 원 초과 부존재로 판결하면 상한 초과 = 위반 → “400만 원을 초과해서는 존재하지 아니한다”로 전부인용. ✓ 상환이행판결은 질적 일부인용이라 처분권주의에 반하지 않으나, 원고가 반대 의사표시를 하면 청구기각.

③ 변론주의 — 주요사실 vs 간접사실논점 019 ★★★★ · 96다53789

✓ 판례는 법규기준설: “주요사실이란 법률효과를 발생시키는 실체법상의 구성요건해당사실”을 말한다. ✓ 취득시효의 기산점은 민법 §245①이 “20년간 점유한 사실”만 규정하고 기산점 규정이 없으므로 간접사실 → 법원은 당사자 주장에 구속되지 않고 소송자료에 의해 진정한 점유 시기를 인정한다. 점유시효취득의 점유권원도 마찬가지로 간접사실(96다53789). ✓ 유권대리 vs 표현대리: 처분권주의 위반은 없다(대리효과 귀속이라는 점에서 차이가 없으므로). 그러나 “표현대리가 성립한다고 하여 무권대리의 성질이 유권대리로 전환되는 것은 아니므로 양자의 구성요건 해당사실 즉 주요사실은 서로 다르다” → 유권대리 주장에 표현대리 주장이 포함되어 있다고 볼 수 없다 = 변론주의 위반. ✓ 두 축을 분리해서 쓰는 것이 배점.

④ 중복된 소제기 금지 — 참가는 중복이 아니다논점 016 · §259 · 2021다2529

✓ 공동소송참가의 실질은 소의 제기이므로 §259 중복소제기 해당 여부가 문제된다. ✓ 판례: 채권자대위소송 계속 중 다른 채권자가 같은 소송물에 관하여 대위권을 행사하며 공동소송참가를 하면 소송경제가 도모되고 판결의 모순·저촉 우려도 없으므로 §259가 금지하는 중복된 소제기에 해당하지 않는다. 추심채권자의 공동소송참가도 같다. ✓ 추심명령 관련 변경판례: 채무자는 당사자적격을 상실하지 않으므로 ⓐ 추심채권자는 §81·§79 승계참가 요건을 충족하기 어렵고, 대신 §83 공동소송참가(사실심 변론종결시까지) 또는 §78 공동소송적 보조참가(상고심까지)로 관여한다. ⓑ 채무자도 공동소송적 보조참가뿐 아니라 공동소송참가까지 가능하다. ✓ 종래판례와 방향이 반대이므로 변경 후 결론으로만 쓸 것.

⑤ 소송계속 중 사망 — 중단 간과 판결의 효력논점 026 ★★★★★ · 15회 사례 35점

✓ 효력: 판례는 위법설 — “중단을 간과한 판결은 ⅰ) 적법한 수계인의 권한을 배제한 절차상 위법은 있으나 당연무효는 아니고, ⅱ) 대리권 흠결을 이유로 상소 또는 재심에 의하여 취소를 구할 수 있다.” ✓ 구제: 확정 전이면 상소(§424① 4호), 확정 후이면 재심(§451① 3호), 하자는 추인(§60)으로 치유된다. ✓ 수계신청 법원: 원칙은 중단 당시 소송이 계속된 법원(§243②). 예외로 사망을 간과하고 판결이 선고된 경우 판례는 선택설 — ⓐ 원심법원에 수계신청 후 상고하거나 ⓑ 상고장을 먼저 제출하고 상고심에서 수계신청해도 수계·상고 모두 적법. ✓ 중단 중 제기된 상소도 부적법하나 상소심에 수계신청을 하여 하자를 치유할 수 있다. ✓ 상속인 중 1인만 수계하면 나머지 상속인의 소송관계는 중단된 채 제1심에 계속된다(93다31993).

⑥ 재소금지 — §267② 4요건논점 · §267② · 15회 사례 25점

✓ 요건 4개: ⓐ 본안의 종국판결 선고 후 소취하일 것 ⓑ 당사자 동일 ⓒ 청구 동일 ⓓ 권리보호이익 동일. 취지는 종국판결 농락 방지 + 판결 모순·저촉 방지. ✓ 소각하판결·소송종료선언 뒤의 소취하에는 적용 없음(본안판결이어야 하고 승·패는 불문). ✓ 함정 3개: ⓐ “원고는 소를 취하하고 피고는 동의한다”는 화해권고결정 확정 = 소취하 합의 → 재소금지 적용(단 승계참가신청은 권리보호이익이 달라 위반 아님). ⓑ 제1심에서 상계항변으로 본안판단을 받았다가 항소심에서 철회한 것은 방어방법 철회에 불과 → 재소금지 부적용, 자동채권으로 별소 가능(2021다275741). ⓒ 항소심에서의 교환적 변경은 결합설상 구소취하 + 신소제기이므로 구청구를 되살리면 재소금지로 부적법. ✓ 후소의 본안판결 후 후소를 취하하면 전소도 유지 불가 → 전소 각하(68다1722).

⑦ 기판력 사례풀이 구조 — 모순금지설과 법원의 조치논점 037 ★★★★★

✓ 판례는 기판력을 후소법원에 대해 전소 확정판결과 모순된 판단을 금지하는 효력으로 본다(모순금지설). ✓ 작용 3유형: 후소 소송물이 전소와 동일하거나, 전소 소송물을 선결문제로 하거나, 전소 소송물과 모순관계에 있는 경우. ✓ 법원의 조치(반드시 유형별로 갈라 쓸 것): ⓐ 동일·모순관계 — 전소 승소확정 원고의 동일 소 = 권리보호이익 없음 → 소각하, 전소 패소확정 원고의 동일 소 = 모순판단 금지의 구속력 → 청구기각. ⓑ 선결관계 — 소각하 불가, 선결문제 한도에서 전소의 기판력 있는 판단을 전제로 본안판결. ✓ 승소확정 후에도 권리보호이익이 인정되는 예외: 변론종결 뒤 승계인을 상대로 승계집행문 부여의 소 등이 문제된 경우. ✓ “승소=각하 / 패소=기각 / 선결=본안” 3점 고정.

⑧ 기판력의 객관적·시적 범위논점 039 ★★★★★ · §216

✓ 객관적 범위: 확정판결은 주문에 포함된 것에 한하여 기판력이 생기고 판결이유 중의 판단에는 생기지 않는다(§216①). 예외로 상계항변은 이유 중 판단이지만 상계로써 대항한 액수의 한도 내에서 기판력이 생긴다(§216②). ✓ 시적 범위 3단: ⓐ 사실심 변론종결 전에 주장했거나 주장할 수 있었던 공격방어방법은 실권효(차단효)로 후소에서 주장 불가. ⓑ 변론종결 후에 새로 발생한 사실은 차단되지 않는다. ⓒ 변론종결 전의 사유라도 소송물이 다르면(동일·선결·모순이 아니면) 차단되지 않는다. ✓ 청구이의의 소와 연결: 청구이의 사유는 전소 변론종결 후에 발생해야 한다(민집 §44②). ✓ 부당집행 구제로서 청구이의의 소는, 확정판결의 집행이 변론종결 후 새로이 발생한 권리남용에 해당하는 경우에도 인정된다.

⑨ 기판력의 주관적 범위 — 변론종결 후의 승계인논점 038 · §218① · 2018다261381

✓ 판단 기준: 제3자가 가지게 된 권리가 승계한 계쟁물(소유권·근저당권)의 일반적 효력으로 발생한 것이고 패소자의 소송물(청구권) 자체를 승계한 것이 아니면, §218①의 변론종결 후의 승계인에 해당하지 않는다. ✓ 예시 2개: ⓐ 인도소송 변론종결 후 소유권을 취득해 물권적 인도청구권을 갖게 된 제3자 ✗ ⓑ 가등기말소청구소송 변론종결 후 근저당권을 취득한 제3자 ✗(2018다261381). ✓ 객관적 범위가 다르면 전소 판결의 변론종결 후 계쟁물을 승계한 자가 후소를 제기해도 기판력이 미치지 않는다(선택 '25). ✓ 고유의 방어방법: 판례는 실질설 — 승계인이 고유의 방어방법을 가지면 실질적으로 당사자 지위를 승계했다고 할 수 없어 §218①의 승계인이 아니다 → 원고는 집행문부여의 소를 제기해야 하고 승계인은 고유 방어방법을 항변으로 제출해 집행문 부여를 막을 수 있다(2000다22775).

⑩ 불이익변경금지 — 상계항변과 항소논점 042 · §414②·§415 · 선택 '20·'21·'22

✓ 원칙: 상소불가분으로 전부 이심되나, 심판범위는 불복신청의 범위에 한한다(1,000만 원 중 400만 원 패소 부분만 항소 → 600만 원 승소 부분은 이심되어도 심판 불가). ✓ 상계 유형 — 제1심이 수동채권·자동채권 모두 인정 + 상계항변 인용 → 청구기각한 뒤 피고가 “수동채권 부존재”를 이유로 항소한 경우: ⓐ 전부 이심되지만 심판대상은 수동채권. ⓑ 항소심이 수동채권 부존재로 판단하면 제1심 판결의 이유가 정당하지 않으므로 항소 인용 → 제1심 판결 취소 → 청구기각 자판. ⓒ §414②에 의한 항소기각(이유교체)은 할 수 없다 — 이유가 달라지면 상계항변에 관한 기판력의 객관적 범위(§216②)가 달라지기 때문. ✓ 이 “§216② 때문에 §414② 불가”라는 한 줄이 배점의 핵심.

⑪ 반소 — 요건 6개와 항소심 반소논점 048 ★★★★ · §412

✓ 요건: ⓐ 동종절차 ⓑ 공통관할 ⓒ 본소 사실심 변론종결 전 ⓓ 본소의 청구 또는 방어방법과 상호관련 ⓔ 본소를 현저히 지연시키지 않을 것 ⓕ 반소이익 + 일반 소송요건. ✓ 단순반소 vs 예비적 반소: 본소의 소송계속은 단순반소의 제기요건일 뿐 존속요건이 아니므로 적법하게 제기된 뒤 본소가 각하·취하되어도 단순반소는 존속한다. 반면 예비적 반소는 본소 기각·각하를 해제조건으로 하는 조건부 반소이므로 본소가 소멸하면 함께 소멸(본소 계속이 제기요건이자 존속요건). ✓ 항소심 반소(§412①): 원고의 동의 또는 이의 없는 본안 변론이 있거나, 없더라도 심급의 이익을 해할 우려가 없는 경우(ⅰ 중간확인의 반소 ⅱ 본소와 청구원인을 같이 하는 반소 ⅲ 제1심에서 충분히 심리한 쟁점 관련 반소 ⅳ 항소심에서의 예비적 반소)에만 허용. ✓ 함정: 항소심에서 원고가 “반소기각의 답변”만 한 것은 §412②의 이의 없는 변론에 해당하지 않는다.

⑫ 참가승계와 소송탈퇴논점 061 · §81·§80 · 15회 사례 40점

✓ 의의: 소송계속 중 소송목적인 권리·의무의 승계인이 독립당사자참가의 방식으로 스스로 참가하는 것(§81). 사실심 변론종결 전에만 가능하고 상고심에서는 불허(선택 '23). ✓ 청구이의의 소 관련: 소 계속 중 집행력 배제를 구하는 채무명의상 청구권을 양수한 자는 §81 승계참가 가능하나, 소 제기 전에 양수한 자의 권리승계참가신청은 부적법. ✓ 승계인 범위(구이론): 소송물 양도는 당연 포함, 계쟁물 양도는 물권적 청구권에 기한 소송 중 취득자는 포함되나 채권적 청구권에 기한 소송 중 취득자는 불포함. ✓ 참가 방식: 전주가 승계사실을 다투지 않으면 편면참가(대립견제 소송관계 불성립), 다투면 전주에게도 청구해야 하는 쌍면참가. 편면참가에서는 소송상태 승인의무가 있으나 쌍면참가에서는 전주의 소송수행 결과에 구속되지 않는다. ✓ 효과: 소송물 양도형에서는 전주가 당사자적격 상실 → 상대방의 동의를 얻어 탈퇴 가능하고, 탈퇴에도 불구하고 판결의 효력은 탈퇴자에게 미친다(§80). ✓ 참가요건 흠결 시 변론을 거쳐 판결로 각하, 본안심리 결과 승계가 인정되지 않으면 청구기각.
