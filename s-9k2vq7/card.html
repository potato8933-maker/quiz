🌙 취침 전 복습 카드 2026. 7. 7.(화)

오늘 공부 범위: 허정 형법 암기장 1~39p (죄형법정주의·형법 적용범위·행위주체·부작위범)

쟁점당 1장씩 12장 + 간격반복 2장 · 어제 다루지 않은 죄형법정주의 판례 중심으로 재구성

생성 07/07 00:11 · 새로고침 시 최신

① 판례변경과 소급효금지 원칙 암기장 p11 · 24 법전협 사례

✓ 형벌의 근거는 법률이지 판례가 아니므로, 행위 당시 판례상 처벌되지 않던 행위를 판례변경 후 처벌해도 형벌불소급 원칙에 반하지 않는다(대판(全) 97도3349). ✓ 따라서 상고심이 기존 판례를 불리하게 변경해 유죄를 선고해도 죄형법정주의(소급효금지)에 위반되지 않아 타당.

② 소급효금지 — 적용 O / X 정리 암기장 p10·11

✓ 소급적용 가능(소급효금지 X): 집행유예 부가 보호관찰(97도703), 전자감시제도, 신상공개명령, 양형기준, DNA 신원확인정보. ✓ 소급적용 불가(소급효금지 O): 가정폭력범죄처벌법상 사회봉사명령(2008어4), 노역장유치(2017도17809), 위치추적 부착기간 하한 가중. ✓ 진정·부진정소급입법은 공·사익 비교형량으로 허용여부 결정(97헌바76).

③ 형법 제1조 제2항 — 동기설 폐지 암기장 p16 · 24 사례·24 기록

✓ 제1조 제2항·형소법 제326조 제4호는 범죄 후 피고인에게 유리하게 법령이 변경된 경우 재판시법(유리한 신법)을 적용한다는 취지임이 문언상 명백 → 종래 동기설(반성적 고려/일시적 사정 구별)을 폐지(대판(全) 2020도16420). ✓ 범죄 불성립·형 경감 시 신법에 따라 처리, 형 폐지 시 면소. ✓ 적용법조 위헌결정 시는 면소 X, 무죄(91도2825).

④ 즉시범·상태범·계속범 암기장 p27

✓ 도주죄는 즉시범 → 간수자의 실력지배 이탈 시 기수·종료. 기수 후 범인 도피를 도우면 범인도피죄일 뿐 도주원조죄 X(91도1656). ✓ 폭처법상 단체 등 조직죄는 즉시범(구성으로 즉시 성립·완성)(2013도6401). ✓ 계속범은 (기수 후라도) 행위종료시까지 공범 성립·공소시효 기산.

⑤ 법인의 범죄능력·형벌능력 암기장 p28·29

✓ 법인은 범죄능력 부정 → 배임죄 주체 X. 법인의 타인 사무는 대표기관의 대표행위로 실현되므로 자연인인 대표기관이 배임죄 주체(대판(全) 82도2595 다수견해). ✓ 범죄능력을 부정하면서도 처벌규정(양벌규정)이 있으면 법인을 행위자와 함께 처벌해 형벌능력은 긍정. ✓ '대표자'는 명칭 불문 실질적으로 경영·사실상 대표하는 자도 포함(2011도15056).

⑥ 양벌규정 — 개별책임·적용대상 암기장 p29·30

✓ 영업주 처벌은 종업원 처벌에 종속 X, 독립된 선임감독상 과실책임(개별책임) → 종업원의 범죄성립·처벌은 전제조건 아님(2005도7673). ✓ 적용대상 아님: 명문 없는 법인격 없는 사단(94도3325), 법인 설립 전 자연인 행위(2015도10388), 1인회사의 1인주주(별개 법인격, 2013도6962). ✓ 합병 소멸법인의 형사책임은 승계 X(2005도4471).

⑦ 작위와 부작위의 구별 — 보라매병원 암기장 p32·33 · 25 법사

✓ 신체적 활동·물리적 작용으로 적극적으로 법익상황을 악화시켜 법익을 침해했다면 원칙적으로 작위에 의한 범죄(작위우선·부작위보충설, 2002도995). ✓ 인공호흡기 제거 퇴원조치는 작위. ✓ 보라매병원: 처=부작위 살인죄(공동정범), 전담의·3년차=작위에 의한 살인방조죄, 1년차=무죄.

⑧ 부작위범의 공범 (부·의·교·간) 암기장 p34

✓ 부작위에 의한 방조는 가능, 교사범·간접정범은 불가. ✓ 부작위범 사이 공동정범: 다수에게 공통된 의무가 부여되고 이를 공통으로 이행 가능할 때만 성립(2008도89). ✓ 하나의 행위가 직무유기(부작위)+범인도피(작위) 충족 시 작위범인 범인도피죄만 성립, 검사는 직무유기죄로만 기소도 가능.

⑨ 부진정부작위범 — 작위의무 발생근거 암기장 p34·35 · 17 사례

✓ 특유요건 = 보증인지위·의무(법·법·선·조) + 행위정형의 동가치성. ✓ 작위의무 발생근거: 법령·법률행위·선행행위 + 신의칙·사회상규·조리(95도2551). ✓ 담배꽁초 실화: 선행행위로 작위의무 인정·확인의무 해태는 작위와 동가치·과실 경합 인과관계 → 각자 단독 실화죄(공동의 목표 없어 과실범 공동정범·동시범 부정, 2022도16120).

⑩ 행위정형의 동가치성 암기장 p36·37

✓ 보호적 지위에서 법익침해 사태를 지배하고 작위의무 이행으로 결과발생을 쉽게 방지할 수 있어야 작위와 동등한 형법적 가치 인정(全 2015도6809). ✓ 동가치성 부정례: 모텔화재 — 소화 가능성·용이성 없어 현주건조물방화치사상 X(2009도12109); 건축자재를 치우지 않은 행위는 위력 업무방해와 동가치 X(2017도13211).
