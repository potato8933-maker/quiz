① 형법 · 필요적 공범 — 대향범 내부가담자에 대한 공범규정 적용암기장 제7장 공범론 p.124~126 · 2009도3642, 2001도5158, 2004도3994, 2011도6287 · [26 23 21 19 17 15 선택][12 사례]

✓ 필요적 공범(대향범)은 2인 이상의 서로 대향된 행위가 있어야 성립 → 형법총칙 공범규정(교사·방조) 적용 불가(2009도3642). ✓ 처벌되지 않는 대향자가 처벌되는 대향자를 적극 교사·방조해도 공범 불성립(법이 불문에 부친 취지). ✓ 매도·매수(2001도5158) / 변호사를 비변호사의 공범으로 처벌 불가(2004도3994) / 처방전 교부받은 자(2011도6287). ✓ 구성요건상 단독 실행 가능한 형식이면 대향범 법리 적용 ✗(2020도7866). ✓ 사례: 경찰관 乙의 수사상황 누설(공무상비밀누설) → 부탁한 甲은 교사범 ✗.

② 형법 · 대향범에 대한 외부적 가담암기장 제7장 공범론 p.126 · 2013도6969 · [22 선택][22 사례][23 법사]

✓ 집합범의 외부관여자는 협의의 공범규정만 적용(다수설) / 대향범: 쌍방 모두 처벌하는 경우 각 대향자에 관여한 외부관여자에게 공동정범·교사·종범 모두 가능. ✓ 일방만 처벌하는 경우: 처벌되는 대향자에게 관여한 외부관여자는 공범규정 적용, 처벌되지 않는 대향자에게 관여한 외부관여자는 적용 ✗. ✓ 판례: 금품 공여자 처벌규정이 없으면 공여행위를 교사·방조해도 상대방 범행의 공범관계 성립 ✗(2013도6969). ✓ 사례: 외부가담자 Y는 진정신분범에 가공 → 제33조 본문으로 교사범.

③ 형법 · 정범과 공범의 구별기준암기장 제7장 공범론 p.127 · 88도1247 · [18 26 선택]

✓ 학설: 객관설(형식적·실질적) / 주관설(의사설·이익설) / 행위지배설(객관+주관 요소로 이루어진 행위지배). ✓ 판례(기능적 행위지배설): 공동정범은 공동의사에 의한 기능적 행위지배가 있음에 반하여, 종범은 그 행위지배가 없는 점에서 양자가 구별된다(88도1247). ✓ 제한적 정범개념(원인설·객관설, 형벌확장사유, 간접정범 인정 필요) vs 확장적 정범개념(조건설·주관설, 형벌축소사유, 간접정범 불요). ✓ 정범개념 우위성: 정범인 乙의 범죄를 먼저 검토.

④ 형법 · 공범종속성설 vs 공범독립성설암기장 제7장 공범론 p.128~129 · 81도2422, 93도1002 · [25 법선][25 23 사례][12 사례]

✓ 종속성설(판례·통설): 공범은 정범의 현실적인 실행행위가 있어야 성립 / 독립성설: 교사·방조행위 자체가 범죄실행행위로서 정범과 무관하게 성립. ✓ 판례: 교사범·방조범 성립에는 먼저 정범의 범죄행위가 인정되는 것이 전제요건(81도2422). ✓ 독립성설은 구성요건적 행위정형성을 무시, 가벌성을 지나치게 확장 → 종속성설 타당. ✓ 제33조 단서: 신분자가 비신분자를 교사한 경우 원칙적으로 존속살해죄 교사범(93도1002), 단 피교사자가 객체착오를 일으켜 다른 사람을 살해했다면 실제 실행한 범위 내(보통살인죄 교사범)에서만 책임.

⑤ 형법 · 공범의 종속형식 (제한적 종속형식)암기장 제7장 공범론 p.130~131 · [18 법사][26 25 사례][17 선택]

✓ 최소한: 구성요건해당성 / 제한적(통설): 구+위법 / 극단적: 구+위+책임 / 초극단적: 구+위+책+가벌성 조건. ✓ 제한적 종속형식 지지 이유: 공범의 처벌근거는 정범의 책임에 가담이 아니라 정범의 불법을 야기·촉진한 데 있음 → 책임 개별화 원칙 / 최소한은 적법행위 가담도 공범 인정, 극단적·초극단적은 책임 개별화에 반함. ✓ 사례(13세 丙을 시켜 절도): 제한적 → 절도죄 교사범(공동교사) + 장물취득 / 극단적 → 책임무능력자 이용 → 특수절도 간접정범(정범이므로 장물죄 ✗).

⑥ 형법 · 간접정범의 본질과 피이용자의 범위암기장 제7장 공범론 p.132~134 · 83도515(全), 86도2395, 70도1638, 2016도17733, 95도1706, 2006도2963, 96도3376, 2003도3945 · [26 25 22 21 19 선택]

✓ 간접정범 = 타인을 생명 있는 도구로 이용(동물·무생물 이용은 직접정범). 본질: 공범설(제한적 정범개념) / 정범설(확장적) / 도구이론·행위지배설(통설, 의사지배). ✓ 제34조 제1항 '어느 행위로 인하여 처벌되지 아니하는 자' = 책임무능력자, 범의 없는 자, 목적·신분 없는 자, 위법성 없는 자, 강제로 의사자유를 억압당한 자(全 83도515). ✓ 피해자 이용: 어린 자식들 익사(86도2395) / 협박해 자상(70도1638) / 강제추행은 자수범 아님(2016도17733). ✓ 고의 없는 도구(95도1706, 2006도2963) / 목적 없는 대통령 이용 내란(全 96도3376) / 정당행위(영장 발부) 이용 직권남용감금(2003도3945).

⑦ 형법 · 신분 없는 고의 있는 도구 / 목적 없는 고의 있는 도구암기장 제7장 공범론 p.135 · 83도515(全) · [25 사례][14 변시 1문]

✓ 문제점: 진정신분범에서 신분자가 신분 없는 고의 있는 도구를 이용한 경우 간접정범이 성립하는지. ✓ 규범적·사회적 행위지배설(다수설): 사실적 의사지배는 없으나 규범적·사회적 행위지배 인정 → 간접정범 성립 / 공범형 간접정범설 / 판례: 목적범·신분범에서 목적·신분 없는 자를 이용한 경우 간접정범 성립 가능(全 83도515). ✓ 반박논리(횡령 사례): ① 피이용자가 객관적 구성요건을 모두 인식 → 도구성 희박 → 교사범 ② 제34조 제1항 문언은 '고의범으로 처벌되는 자'에 간접정범 ✗. ✓ 권리행사방해 사례: 간접정범 / 공모공동정범 / 공범독립성설상 교사범 논거 모두 서술.

⑧ 형법 · 간접정범의 이용행위·실행의 착수시기·처벌암기장 제7장 공범론 p.136 · 2007도7204 · [19 25 선택][18 선택]

✓ 이용행위: 교사·방조가 아닌 사주 또는 이용의 의미. 반드시 타인의 의사를 부당하게 억압해야 하는 것은 아님 → 경영자가 직원들에게 후원회 불법 기부를 하게 한 경우 정치자금법위반죄의 간접정범(2007도7204). ✓ 실행의 착수시기: 주관설(이용행위시설) / 객관설(피이용자의 실행행위시설) / 이분설(선의 도구는 이용행위시, 악의 도구는 피이용자 실행행위시). 암기장 지지: 이용행위시설(이용행위 시 이미 보호법익에 직접적 위험). ✓ 처벌: 외형상 교사에 해당하면 교사의 예, 방조에 해당하면 방조의 예(정범보다 감경).

⑨ 형법 · 간접정범의 한계 — 신분범과 허위공문서작성죄암기장 제7장 공범론 p.137 · 92도1342, 91도2837 · [18 25 선택][22 18 사례][11 사례]

✓ 진정신분범: 신분자 → 비신분자 이용은 간접정범 가능 / 비신분자 → 신분자 이용은 정범적격이 없어 간접정범 ✗(다수설). ✓ 판례: 부정수표단속법상 발행인 아닌 자는 허위신고 고의 없는 발행인을 이용해 간접정범 형태로 허위신고죄 ✗(92도1342). ✓ 허위공문서작성죄: 비공무원이 공무원을 이용한 간접정범 ✗. ✓ 그러나 비신분자가 신분범 범행에 가담하면 제33조 본문에 따라 진정신분범의 공범(공동정범·교사·방조) 성립(91도2837). ✓ 사례: 보조공무원 乙 = 허위공문서작성 간접정범, 비공무원 丁 = 교사범(제227조, 제34조 제1항, 제33조).

⑩ [간격반복] 민사 사례 · 청구이의 — 별소에서의 소송상 상계의 효력 발생 시기10/20 민사 사례형 첨삭 1-2-2 (3.0/15.0) · 2011다3329, 2022다284520 · 민사집행법 제44조

✓ 청구이의의 이의사유는 변론종결 뒤에 생긴 것이어야 함(민사집행법 제44조 제1항·제2항) → 소송 유형이 나오면 그 근거 조문부터 적고 시작. ✓ 소송상 상계의 효력은 법원의 실질적 판단 시 확정(2011다3329). ✓ 확정판결의 사실심 변론종결 이전에 별소에서 상계 의사표시가 있었더라도, 변론종결 이후에 별소에서 상계 주장을 받아들이는 법원의 실질적 판단이 있었다면 변론종결 후에 생긴 사유(대법원 2025. 8. 28. 선고 2022다284520). ✗ '상계 자동채권 기판력·모순금지설'로 대체하지 말 것.

⑪ [간격반복] 형사 사례 · 휴대전화 증거능력 — 사인 이용 강제처분과 미성년자의 참여권10/20 형사 사례형 첨삭 1-3 (9.5/20.0) · 2022도2071 · 판례 오해형

✓ 수사기관의 지시·요청에 따라 사인이 제삼자가 지배·관리하는 물건을 취거하여 수사기관에 전달하면 수사기관이 사인을 이용해 강제처분을 한 것 → 영장의 제시, 참여권의 보장 등 절차 준수 요구(2022도2071). ✓ 의사능력이 있는 미성년자나 그 변호인에게 참여 기회가 보장되어야 하고, 친권자에게 참여 기회가 보장되었다는 이유만으로 적법해지지 않음. ✓ 영장 제시도 친권자가 아니라 참여 능력이 충분한 피고인에게 해야 함. ✗ '임의제출물'로 출발하지 말 것(乙이 실질적 피압수자) → 제308조의2 위법수집증거.

⑫ [간격반복] 공법 기록 · 위법한 이중처분과 효력기간 경과10/20 공법 기록형 첨삭 1-3 (12.0/20.0) · 행정소송법 제23조 제2항 · 판례 미숙형 + 포섭 부실형

✓ 당초 제재적 행정처분에서 정한 효력기간이 경과하면 그로써 처분의 집행은 종료되어 효력이 소멸 → 그 후 동일한 사유로 다시 제재처분을 하는 것은 위법한 이중처분. ✓ 처분에서 효력기간의 시기와 종기를 정해 두었는데 그 시기와 종기가 집행정지기간 중에 모두 경과한 경우에도 특별한 사정이 없는 한 마찬가지. ✓ 집행정지 결정(행소법 제23조 제2항)으로 효력기간 진행이 정지되었다 부활하는 날짜를 계산해 적용(12. 1. 선고 → 부활 → 12. 10. 종료). ✓ '동일한 사실관계'에 그치지 말고 기록상 처분사유(일자·상대방·금액)를 그대로 옮길 것.
