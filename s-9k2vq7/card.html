━ 오늘 범위(추정) · A. 채권자대위소송 ━

① 대위소송의 법적 성질 — 「3요건은 소각하, 피대위권리는 청구기각」민법 제404조 · 병행형 법정소송담당 ★★★

✓ 성질: 판례는 채권자대위소송을 「채권자가 스스로 원고가 되어 채무자의 제3채무자에 대한 권리를 행사하는 것」이라 하여 법정소송담당 중 「병행형」으로 본다(갈음형 ✗). ✓ 당사자적격 요건 3개: i) 피보전채권 ii) 보전의 필요성 iii) 채무자의 권리불행사 — 흠결 시 「소각하」. ✓ 소송물은 iv) 피대위권리 — 흠결 시 「청구기각」. ⚠ 이 3+1 분기가 대위소송 문제의 전부입니다. 답안은 「적격 3요건 검토 → 각하 여부 → 본안(피대위권리) → 기각 여부」 순으로 고정하십시오. 각하와 기각을 바꿔 쓰면 결론 오류로 직결됩니다.

② 피보전채권의 흠결 — 시효완성이면 곧바로 소각하2007다64471 · 직권조사사항 ★★

✓ 피보전채권이 인정되지 않으면 당사자적격이 없어 대위소송은 부적법하다. ✓ 소멸시효 완성형(출제 빈발): 채권자가 대위소송을 제기하는 한편 채무자를 상대로 피보전채권에 기한 이행의 소를 제기했는데, 채무자가 시효를 원용하는 항변을 하여 피보전채권의 시효가 적법하게 완성된 것으로 판단되면, 「채권자는 더 이상 채무자를 대위할 권한이 없게 된다」 → 피보전채권 부존재 = 당사자적격 흠결 = 소각하(2007다64471). ✓ 채무자가 실존인물이 아니거나 사망한 사람인 경우도 부적법. ✓ 직권조사사항: 피보전채권의 존재는 소송요건이므로 직권조사사항이나, 법원에 직권탐지 의무까지는 없고(주장·증명책임은 당사자), 다만 「현출된 모든 소송자료를 통해 의심할 만한 사정이 발견되면 직권으로 추가 심리·조사」해야 한다.

③ 대위소송과 중복소제기 — 3유형 전부 「중복 긍정」제259조 · 표준 3유형 ★★★

✓ ⓐ 대위소송 계속 중 채무자가 별소: 「판결의 모순·저촉 방지」라는 중복소제기금지의 취지상 당사자는 달라도 실질적으로 동일소송이므로, 채무자가 대위소송 계속을 알든 모르든 채무자의 후소는 중복소제기. ✓ ⓑ 채무자의 소 계속 중 채권자가 대위소송: 법정소송담당상 채무자가 받은 판결의 효력이 채권자에게 미치므로 역시 중복소제기 해당(87다카1618 계열). 더하여 — 대위권 행사 당시 이미 채무자가 권리를 행사한 이상 대위요건 흠결로 당사자적격도 없어 부적법(92다○○16) ← 두 축을 모두 써야 만점. ✓ ⓒ 다른 채권자의 대위소송: 취지가 모순·저촉 방지이므로 당사자가 달라도 실질적 동일소송 → 중복소제기(선택형 16·21·24회). ⚠ 대위는 3유형 모두 중복 긍정 — 취소소송과 정반대입니다.

④ 대위소송의 기판력 — 「알았을 경우에만」, 집행력은 부정제218조 3항 · 79마232 ★★

✓ 원칙(제218조 3항): 소송담당자가 받은 판결의 기판력은 권리주체에게 미치나, 「갈음형」·직무상 당사자·임의적 소송담당에 적용된다. ✓ 병행형인 대위소송은 예외 — 「채권자대위소송이 제기된 사실을 채무자가 알았을 경우에만 기판력이 채무자에게 미친다」. ✓ 집행력은 부정: 채권자의 청구인용판결이 확정되어 기판력이 채무자에게 미치는 경우라도, 「집행력만은 채권자·제3채무자 간에만 생기고 채무자와 제3채무자 사이에는 생기지 아니한다」(79마232). ✓ 역방향: 채무자가 제3채무자에게 소를 제기해 패소 확정된 후 채권자가 대위소송을 제기하면, 당사자는 달라도 실질상 동일 소송이라 기판력이 미치고, 모순금지설에 따라 후소법원은 청구기각 판결을 한다.

━ 오늘 범위(추정) · B. 채권자취소소송 ━

⑤ 취소소송의 소송물 = 「채권자 자신의 채권자취소권」민법 제406조 · 2004다55○○ ★★★

✓ 판례(구소송물론)에 의하면 채권자취소소송의 소송물은 「채권자 자신의 채권자취소권(민법 제406조)」이며, ⓐ 피보전채권이 있을 것 ⓑ 사해행위가 있을 것 ⓒ 사해의사가 있을 것을 요건으로 하고, 원상회복은 ⓓ 원물반환 ⓔ 가액배상으로 한다 — 이 5개는 전부 「공격방법」입니다. ✓ 따라서 채권자가 사해행위 취소를 청구하면서 피보전채권을 추가하거나 교환하는 것은 취소권(소송물)을 이유 있게 하는 공격방법의 변경일 뿐이어서 소의 변경이 아니다. ⚠ 「소송물 = 취소권 / 피보전채권 = 공격방법」이라는 이 한 줄이 아래 ⑥의 중복 판단과 소변경·시적 범위 문제를 동시에 지배합니다.

⑥ 취소소송과 중복소제기 — 「사람이 다르면 별개, 채권이 바뀌면 중복」2003다19558 · 2012다○○603 ★★★

✓ ⓐ 수인의 채권자가 각각 제기(甲→B 취소소송 계속 중 乙→B 제기): 취소소송은 채권자가 「자신의 권리로서」 취소권을 행사하는 것이어서 소송물이 각 채권자의 취소권으로 서로 별개의 권리 → 중복소제기 아님(2003다19558). ✓ ⓑ 동일 채권자가 피보전채권만 바꿔 다시 제기(대여금채권 → 손해배상채권으로 변경하여 같은 수익자 B에게 재차 제기): 소송물은 제406조의 취소권이고 피보전채권은 공격방법에 불과하므로 전·후 소송물이 동일 → 중복소제기 해당. ⚠ 대위(③)는 3유형 전부 중복 긍정 / 취소는 ⓐ 부정·ⓑ 긍정 — 이 대비가 결합형 출제의 핵심 분기점입니다.

⑦ 사해행위취소의 소 — 피고적격·의무이행지·가액배상형성의 소 · 원물→가액 포섭 ★★

✓ 피고적격: 사해행위취소의 소에서 채무자는 피고적격이 없고, 수익자 또는 전득자만 피고적격을 가진다(형성의 소 — 명문 규정이 없으면 소송물인 권리관계에 가장 강한 이해관계가 있는 자). ✓ 의무이행지: 「채권자의 주된 목적은 사해행위의 취소 그 자체보다는 일탈한 책임재산의 회복에 있으므로」, 의무이행지는 취소 대상인 법률행위의 의무이행지가 아니다. ✓ 원물반환 청구에 가액배상 포함: 「사해행위를 전부 취소하고 원상회복을 구하는 채권자의 주장 속에는 사해행위를 일부 취소하고 가액의 배상을 구하는 취지도 포함되어 있으므로, 원상회복만을 구하는 경우에도 법원은 청구변경 없이 가액의 배상을 명할 수 있다」. ✓ 제척기간은 제소기간이므로 도과 여부는 직권조사사항 — 당사자의 주장 없이 제척기간 도과를 이유로 각하한 판결은 위법(석명 없이 불의타를 주는 경우).
