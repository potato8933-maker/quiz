① 범죄의 성립요건·처벌조건·소추조건 구별 암기장 p26

✓ 성립요건(구성요건·위법성·책임): 객관적 구성요건요소는 고의의 인식대상 → 결여 시 구성요건적 고의 조각. 위법성 결여 시 정당방위 불가, 책임 결여 시 정당방위 가능. ✓ 처벌조건·소추조건: 고의의 인식대상 아님 → 결여돼도 정당방위 가능, 이에 교사·방조한 자는 (제한적 종속성설) 공범 성립 가능. ✓ 판결: 성립요건 흠결=무죄 / 처벌조건 흠결=형면제 / 소추조건 흠결=공소기각. ✓ 계속범은 (기수 후라도) 행위종료시까지 공범 성립·정당방위 가능, 공소시효도 행위종료시 기산.

② 부작위범의 공범 (부·의·교·간) 암기장 p34

✓ 부작위에 의한 방조는 가능하나, 부작위에 의한 교사·간접정범은 불가. ✓ 부작위범 사이의 공동정범: 다수에게 공통된 의무가 부여되고 공통으로 이행할 수 있을 때에만 성립(2008도89). ✓ 진정부작위범도 미수처벌 규정 존재(예: 퇴거불응죄). ✓ 행정청 지시 불이행형 범죄는 진정부작위범 → 의무이행기간 경과로 기수(93도1731).

③ 부진정부작위범 — 작위의무·처벌·정범과 공범 구별 암기장 p34·39

✓ 작위의무 발생근거 [법·법·선·조] = 법령·법률행위·선행행위·조리(신의칙·사회상규)(95도2551). ✓ 처벌: 발생된 결과에 의해, 작위범과 동일한 법정형(제18조). ✓ 정범/공범 구별은 종범설(판례) — 은행지점장이 부하직원의 배임행위를 방지하지 않으면 업무상배임 방조범(84도1906). [제8회 변시 제2문]

④ 상업사용인 — 지배인 vs 부분적 포괄대리권 사용인 간격반복 · 퀴즈 오답
