① 청구이의의 소 — 관할은 직분관할·전속박승수 암기장 관할 · 민집 제44조①

✓ 민집 제44조 제1항의 '제1심 판결법원' = 직분관할 → 성질상 전속관할(직권조사사항). ✓ 지방법원 합의부의 항소심인 고등법원이 한 판결을 대상으로 한 청구이의의 소 → 지방법원 합의부의 전속관할. ✓ 이에 부수한 강제집행정지 신청도 수소법원 전속관할. ✓ 사례형·선택형 모두 기출 표시 — 관할 문제는 '항소심 판결이라도 1심 법원'으로 고정.

② 청구이의 사유 ① 상계권 비실권 + 별소 소송상 상계박승수 암기장 기판력 시적범위 · 민집 제44조② · 2022다284520

✓ 변론종결 전 상계적상이었어도 변론종결 뒤 상계 의사표시 → 제44조②의 '이의원인이 변론종결 뒤에 생긴 때', 자동채권 존재를 알았든 몰랐든 적법한 청구이의 사유(상계권 비실권설). ✓ 최근 판례: 변론종결 이전 별소에서 소송상 상계 의사표시 → 변론종결 이후 별소 법원이 이를 받아들이는 실질적 판단 → 확정판결 기판력에 저촉되는 등 특별한 사정 없는 한 변론종결 이후에 생긴 사유 = 적법한 청구이의 이유.

③ 청구이의 사유 ② 표준시 후 형성권 — 실권 여부박승수 암기장 기판력 시적범위 · 95다42195

✓ 취소권·해제권 등 일반 형성권 → 실권 긍정(무효사유도 차단되는데 더 약한 사유가 남으면 불균형). ✓ 상계권 → 실권 부정. ✓ 건물매수청구권 → 실권 부정: 토지인도·건물철거 패소 확정 후에도 별소로 매매대금 청구 가능(소송물 상이, 95다42195). ✓ 한정승인 → 실권 부정: 주장 안 해 유보 없는 판결 확정돼도 청구이의의 소 허용(책임범위는 심판대상 X). ✓ 상속포기 → 실권 긍정(채무 존재 자체 문제). ✓ 백지보충권 → 실권 긍정.

④ 편취판결과 청구이의 · 청구이의 중 승계참가박승수 암기장 판결의 편취·소송승계 · 제81조

✓ 금전 편취판결에 의한 강제집행 = 변론종결 뒤 새로 발생한 권리남용 → 청구이의의 소 인정. ✓ 소유권이전등기 등 의사진술을 명하는 판결 → 확정과 동시에 효력, 집행절차 불요 → 청구이의 소의 이익 없음. ✓ 청구이의의 소 계속 중 집행권원에 표시된 청구권을 양수한 자 → 소송의 목적인 채무 승계 → 제81조 승계참가 가능. ✓ 청구이의 소 제기 전 양수한 자의 승계참가 신청 → 부적법. ✓ 참가승계는 사실심 변론종결 전까지, 상고심 X.

⑤ 민집 구제 3분법 — 청구이의 vs 제3자이의9/25 상법사례 첨삭 제5문 (2/5) · 민집 제44·48·16조

✓ §44 청구이의 = 채무자가 집행권원의 실체 청구권 소멸·변경을 다툼. ✓ §48 제3자이의 = 제3자가 집행목적물의 소유권 등 양도·인도를 막는 권리 주장. ✓ §16 집행에 관한 이의 = 절차상 위법. ✓ 첨삭 오답: 위탁매매 목적물은 위탁자와 위탁매매인의 채권자 사이에서 위탁자 소유(상법 제103조) → 위탁자 A의 구제수단은 청구이의가 아니라 제3자이의의 소(민집 제48조). ✓ '누가 원고인가'로 소 종류를 먼저 고정.

⑥ 추심채권자의 당사자적격 — 변경판례박승수 암기장 제3자 소송담당 · 전합 변경

✗ 종래: 추심명령 → 채무자는 이행의 소 당사자적격 상실(소각하), 추심채권자 = 갈음형 소송담당. ✓ 변경판례: 추심명령이 있더라도 채무자는 제3채무자를 상대로 피압류채권 이행의 소를 제기할 당사자적격을 상실하지 않는다. ✓ 근거: 추심명령 위반 아님·상실 근거 규정 없음 / 추심채권자·제3채무자에게 불리하지 않음(응소부담 최소화) / 분쟁의 일회적 해결 / 채무자는 시효중단·제소기간 준수, 추심권 소멸 대비 집행권원 확보 이익. ✓ 보상금 증액 청구의 소도 채무자 적격 유지(전합).

⑦ 추심 — 참가 방식과 중복제소박승수 암기장 제3자 소송담당 · 제83·78·259조

✓ 채무자의 이행소송에 추심채권자: 승계 없음 → 제81·79조 승계참가 X, 공동소송참가(제83조, 사실심 변론종결까지) 또는 공동소송적 보조참가(제78조, 상고심까지). ✓ 추심소송에 채무자: 공동소송적 보조참가 + 공동소송참가도 가능. ✓ 공동소송참가는 실질이 소제기여도 제259조 중복제소 X(대위소송 공동소송참가와 동일 논리). ✓ 반면 채무자 이행소송 계속 중 추심채권자의 별소, 한 추심채권자 소송 중 다른 추심채권자의 별소 → 실질적으로 동일 사건 → 중복제소로 부적법.

⑧ 추심 — 기판력의 확장과 추심권 포기 화해박승수 암기장 기판력 주관적 범위 · 제218조③ · 2016다35390

✓ 변경판례: 채무자가 이행소송에서 받은 확정판결 → 추심채권자에게 미침(2021다239301 관리단 판결 참조). 추심소송 확정판결 → 채무자에게 미침(제218조 제3항) → 결국 다른 추심채권자에게도 미침. 추심명령 시기가 변론종결 전·후 불문. ✓ 채무자 승소 시 추심채권자는 승계집행문(민집 제25·31조)으로 바로 집행. ✓ 추심소송 화해 중 '나머지 청구 포기' = 자기 추심권 포기일 뿐 피압류채권 포기 X → 다른 추심채권자에게 효력 X(2016다35390).

⑨ 전부명령과 당사자적격박승수 암기장 제3자 소송담당

✓ 전부채권자는 추심채권자와 달리 제3자 소송담당이 아니라 '자기 권리'를 행사하는 자. ✓ 전부채무자가 제3채무자를 상대로 이행청구 → 이행의 소이므로 자기가 이행청구권자임을 주장하는 이상 원고적격 있음 → 소 자체는 적법. ✓ 다만 전부로 채권이 이전되어 실체법상 이행청구권이 없으므로 본안에서 청구기각. ✓ 대비 암기: 추심 → 채무자 적격 유지(변경판례)·본안 판단 / 전부 → 적격 있으나 기각.

⑩ 가압류된 금전채권 — 이행소송과 판결박승수 암기장 소의 이익(이행의 소) · 선택 기출

✓ 금전채권에 대한 가압류는 채무자가 제3채무자로부터 급부를 추심하는 것만 금지 → 채무자는 제3채무자를 상대로 이행의 소 제기 가능, 법원은 가압류를 이유로 배척할 수 없음. ✓ 본안: 청구가 이유 있으면 무조건 전부 청구인용판결. ✓ 이유: 이행판결이 있더라도 제3채무자는 집행단계에서 저지하면 되기 때문. ✓ 소유권이전등기청구권과의 대비(다음 카드)가 선택형 단골.

⑪ 가압류된 소유권이전등기청구권박승수 암기장 소의 이익(이행의 소) · 선택 기출

✓ 이행의 소 제기 자체는 적법. ✓ 그러나 이전등기 판결 = 의사진술을 명하는 판결 → 확정되면 채무자가 일방적으로 등기신청, 제3채무자는 저지할 방법이 없음 → 가압류 해제를 조건으로 한 인용판결. ✓ 그래서 제3채무자는 응소하여 가압류 사실을 주장·증명할 의무. ✓ 가압류 사실은 항변사유이지 직권조사사항 X → 소장에 기재돼도 선행자백에 불과, 피고가 원용해야 고려 → 피고 무답변·불출석이면 가압류를 알아도 전부승소 판결.

⑫ 직무집행정지가처분 — 피신청인·대표권박승수 암기장 당사자적격(확인의 소)

✓ 대표이사 선임 주총결의 효력을 다투는 본안과 관련해 甲에 대한 직무집행정지·직무대행자선임 가처분 → 피신청인은 회사가 아니라 이사 甲. ✓ 단체 대표자 지위 부존재확인의 소에서 단체를 대표할 자는 원칙적으로 그 대표자이나, 직무집행정지가처분을 받았다면 가처분에 특별한 정함 없는 한 본안소송에서 단체 대표권 포함 일체의 직무집행에서 배제. ✓ 그 대표자를 송달받을 사람으로 한 소장 송달 → 부적법, 그 대표자의 소송행위·그에 대한 소송행위 모두 무효.

⑬ [간격반복] [상법사례] 어음 변조 — 상환청구권 보전 기준 만기9/25 상법사례 첨삭 6-(2) · 0.5/15점(회차 최저) · 오늘 상법 파이널(어음) 연계

✓ 어음법 제69조: 변조 전 기명날인자 → 원래 문구, 변조 후 기명날인자 → 변조된 문구에 따라 책임. 변조의 항변 = 물적항변. ✓ 상환청구권 보전도 변조 전 어음행위자는 변조 전 만기, 변조 후는 변조 후 만기 기준(95다49936). 제시기간 = 지급을 할 날 + 2거래일(어§38①). ✓ 발행인은 보전 무관 주채무자. ✓ 증명책임: 변조가 명백 → 소지인, 감쪽같으면 → 채무자. 암기: "자기가 도장 찍을 때의 만기로 따진다."

⑭ [간격반복] [형사사례] 비약적 상고의 효력과 대법원의 조치10/20 10모 형사사례 첨삭 1-5 · 1/10점(결론 반대)
