② 선정당사자의 지위 — 할 수 있는 행위·없는 행위박승수 암기장 논점054

③ 선정당사자 자격상실·흠결 간과박승수 암기장 논점054 · 선택 16·17·24

④ 통상의 보조참가 — 참가이유(법률상 이해관계)박승수 암기장 논점055 · 제71조

✓ 요건: 타인 간 소송계속 / 소송결과에 법률상 이해관계 / 참가신청 / 현저한 지연 없을 것. ✓ 통상공동소송인은 서로 타인 → 보조참가 가능, 필수적 공동소송인은 상대방 측 참가 불가. ✓ 이해관계 = 판결주문의 권리관계 존부에 직접 영향(판결이유만으로는 원칙 X). 예외: 공동불법행위자는 피해자가 다른 공동불법행위자를 상대로 한 소송에 원고 측 참가 가능(99다12796). ✓ 사실상·경제상·감정상 이해관계 X. ✓ 이의 없이 본안 변론 → 이의권 상실, 다만 법원은 직권으로 소명 명령 가능 → 결정으로 허부. ✓ 참가 취하해도 참가적 효력은 받음.

⑤ 보조참가인의 종속성·독립성·제한박승수 암기장 논점055 · 제76조

✓ 종속성: 참가인에게 사망 등 사유 생겨도 중단 X. 참가인의 상소는 피참가인의 상소기간 내(상고이유서 제출기간도 동일). ✓ 독립성: 별도 기일통지·송달, 참가인 출석으로 기일 해태 방지. ✗ 할 수 없는 행위: ① 참가 당시 피참가인도 못 하는 행위(상고심 새 사실·증거, 상소기간 경과 후 상소) ② 피참가인 행위와 어긋나는 행위(제76조②) — 단 자백간주된 사실을 다투는 것은 명백히 적극적 배치 아님 → 허용[선택 20·24·27] ③ 불리한 행위(포기·인낙·화해·자백·상소취하) ④ 청구변경·반소·중간확인 ⑤ 피참가인의 상계권 행사.

⑥ 참가적 효력 — 요건·범위·배제박승수 암기장 제77조 · 86다카2289

✓ 성질: 기판력과 다른 특수효(참가적 효력설, 86다카2289) — 피참가인 패소 후 피참가인 vs 참가인 2차 소송에서 판결 부당 주장 불가. ✓ 요건: 본안판결 + 확정 + 소송수행 기회. 화해권고결정·조정에 갈음하는 결정(2016다221005)으로 종료 시 참가적 효력 X. ✓ 주관적 범위: 피참가인↔참가인 사이만(상대방↔참가인 X). 객관적 범위: 주문 + 패소이유가 된 사실상·법률상 판단 중 공동이익으로 다툴 수 있었던 사항. ✓ vs 기판력: 패소 시만·항변사항·이유 중 판단에도·배제 사유 있음(행위 불가·어긋남·방해·고의과실 불행사).

⑦ 소송고지 — 참가적 효력·시효중단박승수 암기장 논점056 · 제84조

✓ 의의: 소송계속 중 당사자가 참가할 이해관계 있는 제3자에게 소송계속 사실을 통지. 고지자: 당사자·보조참가인·피고지자. ✓ 피고지자에게 참가적 효력 — 다만 고지자와 공동이익으로 주장할 수 있었던 사항에 한하고, 고지자·피고지자 간 이해 대립 사항엔 미치지 않음. ✓ 실체법상 효과: 민법 제174조 최고의 효력. 6월 기간은 고지일이 아니라 당해 소송이 종료된 때부터 기산. 시효중단 효력은 제265조 유추 → 소송고지서를 법원에 제출한 때 발생(2014다16494).

⑧ 공동소송적 보조참가 — 요건·독립적 지위박승수 암기장 논점057 · 제78조

✓ 요건: 타인 간 소송계속 + 당사자적격 없음 + 판결 효력이 미침(적격 있으면 공동소송참가). 예: 갈음형 소송담당의 권리귀속주체, 형성력 확장 소송, 제소기간 경과 후 참가(기간 내면 공동소송참가). 채권자대위소송 중 채무자 참가 = 공동소송적 보조참가, 주주대표소송 중 회사 참가 = 공동소송참가. ✓ 통상 보조참가와 차이 3: 피참가인과 어긋나는 행위 가능 / 참가인 사유로 중단(제67조③ 준용) / 상소기간 독자 기산(피참가인 상고이유서 기간 도과해도 참가인 제출 적법). ✓ 그 외는 종속적 — 참가 당시 피참가인이 못 하는 행위 불가.

⑨ 공동소송적 보조참가 — 피참가인의 소 취하박승수 암기장 논점057 · 선택 22·27

✓ 항소심에서 피참가인의 소 취하: 소가 처음부터 계속되지 않은 것으로 간주 → 재판의 효력과 직접 관련 없는 행위 → 참가인 동의 없어도 유효(유사필수적 공동소송에서도 일부 원고 취하에 동의 불요). ✓ 재심의 소 취하: 확정판결에 대한 불복 기회를 상실시켜 확정판결 효력을 배제할 수 없게 함 → 재판의 효력과 직접 관련 + 판결효가 미치는 참가인에게 불리 → 재심의 소에 공동소송적 보조참가인이 참가한 후에는 참가인 동의 없으면 효력 없음. ✓ 판결효: 피참가인↔참가인 = 참가적 효력, 피참가인↔상대방 판결의 기판력이 참가인에게 미침.

⑩ 공동소송참가 — 요건·한계 사례박승수 암기장 논점058 · 제83조

✓ 요건: 타인 간 소송계속(상고심 불가 — 신소제기 실질) + 당사자적격 + 합일확정(기판력 확장 → 유사필수적 공동소송). 고유필수적 공동소송 누락자도 참가로 보정 가능(통설). ✓ 참가요건 = 직권조사사항 → 흠 있으면 종국판결로 각하. ✓ 채권자대위소송 중 다른 채권자의 공동소송참가: 피대위채권이 동일하면 소송물 동일 → 적법. 원고가 일부청구 명시 시 참가인 청구액이 원고 청구액을 초과하지 않는 한 적법. ✓ 회사대표소송 중 회사 참가 = 공동소송참가, 중복소제기 아님[선택 14·15·17·21]. ✓ 채무자 대위소송 참가(통지 후 적격 상실) = 공동소송적 보조참가.

✓ 구조: 3면소송설(91다21145). 상고심 참가 불가. 쌍면·편면 모두 허용. ✓ 권리주장참가: 본소청구와 주장 자체로 양립 불가면 충족(본안 결과 양립해도 부적법 X). 적법 — 소유권(일물일권, 93다5727), 채권 이중양도(91다21145), 하나의 매매에 기한 등기청구권 다툼(86다148), 병합청구 중 하나라도 양립불가. 부적법 — 부동산 이중매매, 매매 vs 점유취득시효 등기청구. ✓ 사해방지참가: 양립 가능해도 됨, 사해의사설. 원고 상대 사해행위취소 구하는 참가는 상대효로 목적 달성 불가 → 부적법. ✓ 제3자 권리 부존재확인은 확인이익 X, 수 개 청구는 청구별로 요건(2022다241600).
