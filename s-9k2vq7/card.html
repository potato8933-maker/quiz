① 채무자위험부담주의 — 원칙 §537C-9 · 2008다98655 · 2회·11회 선택

✓ 쌍무계약 당사자 일방의 채무가 당사자 쌍방의 책임 없는 사유로 이행불능이 되면 채무자는 상대방의 이행을 청구하지 못한다(§537). 요건 = i) 대가적 견련관계 있는 상환적 채무 ii) 후발적 불능(원시적 불능은 §535 계약체결상 과실) iii) 쌍방 무귀책. ✓ 효과: 반대급부청구권 소멸 → 기이행분은 부당이득(§741)으로 청산. "매매목적물이 경매절차에서 매각되어 쌍방 무귀책으로 이행불능이 된 경우 매도인은 이미 받은 계약금을 반환하고, 매수인은 점유·사용으로 얻은 임료 상당 부당이득을 반환할 의무가 있다"(2008다98655·98662, 표준판례596). ✓ §537·§538은 임의규정(2003두3734).

② 채권자위험부담 — 예외 §538 + 이행인수C-10 · 2009다5193 · 2001다79013

✓ 채권자의 책임 있는 사유로, 또는 수령지체 중 쌍방 무귀책으로 이행불능이 되면 채무자는 반대급부를 청구할 수 있다(§538①). ✓ 여기서 채권자의 "책임 있는 사유"는 통상의 고의·과실이 아니라 "채무자의 이행 실현을 방해하고, 피할 수 있었다는 점에서 신의칙상 비난받을 수 있는 작위·부작위"(2001다79013). ✓ 대표례: 매수인이 저당권 피담보채무를 이행인수하고 불이행하여 경매로 매도인이 소유권을 상실한 경우 → 매수인이 대가위험 부담, 다만 매도인이 소유권이전의무를 면해 얻은 이익(경매대금)은 §538②로 상환(2009다5193, 표준판례600). ✓ §538① 2문 적용 시 대가위험 이전에는 채무자의 변제제공(현실·구두)이 필요(2001다79013, 3회 선택).

③ 제3자를 위한 계약 — 기본관계 해제 시 원상회복 상대방C-13 · 2005다7566 · 6·8회 선택

✓ 제3자는 수익의 의사표시를 해야 채권을 취득한다(§539②, 묵시적 표시도 가능 2003다45267). 낙약자는 기본관계상 항변으로 수익자에게 대항할 수 있다(§542). ✓ 핵심: 기본관계 계약이 해제된 경우 청산은 낙약자·요약자 사이에서 이루어져야 하므로, 낙약자가 이미 제3자에게 금전을 급부했더라도 제3자에게 원상회복·부당이득 반환을 구할 수 없다(2005다7566·7573, 표준판례605 / 무효·취소도 동일 2010다31860). 단축급부의 실질이기 때문. ✗ 이미 이행한 것이 물건(등기)이면 물권행위 유인성으로 소유권이 복귀 → 낙약자가 수익자에게 직접 말소청구 가능. ✓ 요약자는 낙약자의 귀책 이행불능·지체 시 제3자의 동의 없이 해제할 수 있다(69다1410, 표준판례609).

④ 계약금에 의한 해제 — §565 요건사실C-15 · 91다2151 · 2022다247187

✓ 요건: i) 계약금이 전부 교부될 것(2007다73611) ii) 해약권을 배제하는 다른 약정이 없을 것(2008다50615) iii) 당사자 일방이 이행에 착수하기 전일 것 iv) 교부자는 포기, 수령자는 배액 상환(§565①). ✓ 계약금이 위약금 특약으로 인정되어도 그 특약은 §565① "다른 약정"이 아니며 위약금과 해약금이 병존한다(91다2151, 표준판례635). ✓ 가계약금에 해약금 약정이 있었다고 인정하려면 약정 내용·동기·경위·목적·거래관행에 비추어 "정식 계약 전까지 포기/배액상환으로 계약을 체결하지 않기로 한 약정"이 명백히 인정되어야 한다(2022다247187).

⑤ "이행의 착수"의 판단 — 긍정례·부정례·이행기 전 착수C-16 · 99다62074 · 6회 사례

✓ 착수 = 객관적으로 외부에서 인식할 수 있을 정도로 이행행위의 일부를 하거나 이행의 전제행위를 하는 것. 단순한 준비로는 부족하고, 완전한 이행제공 정도까지 요하지도 않는다. ✓ §565①의 "당사자의 일방"은 쌍방 중 어느 일방을 뜻하므로 스스로 착수한 자도 해제 불가(99다62074). ✓ [긍정] 중도금 제공(93다11968), 중도금 일부 지급에 갈음한 채권양도 약정에 제3자가 참석한 경우(2005다39594). ✓ [부정] 매도인이 이행최고·잔대금 청구소송을 제기한 것만으로는 착수 아님(2007다72274, 6회 사례) / 토지거래허가구역에서 계약금만 주고받은 상태에서 허가를 받은 것만으로는 착수 아님 → 해제 가능(2008다62427, 5회 선택). ✓ 이행기 전 착수도 원칙 허용(특약 등 특별사정 없는 한).

⑥ 이행지체를 이유로 한 법정해제 — §544 이행제공의 정도C-19 · 85다카2197 · 2022다238053

✓ 요건사실: i) 채무자의 이행지체(이행기 도래·이행가능·귀책·위법) ii) 상당한 기간을 정한 최고 iii) 기간 내 불이행(§544). ✓ 동시이행관계인 경우 해제권 발생을 위한 이행제공은 한 번의 제공으로 족하나, 상대방의 행위가 필요하면 현실이행 준비 완료 + 통지 + 수령최고가 있어야 하고 단순한 준비태세만으로는 부족(85다카2197). ✓ 다만 제공의 정도는 신의칙상 합리적으로 정해지므로, 상대방이 비협조·미준비면 이쪽도 그에 상응한 준비로 족하다(2012다65867 / 2024다237757). ✓ 해제통지에 수령거부 취지가 없으면 그 자체로 "이행의 최고"가 되지만, 동시이행 반대급부를 지는 채권자는 스스로 변제제공을 해야 해제할 수 있다(2022다238053, 표준판례616, 10회 선택). ✓ 일부지체는 일부무효 법리 준용(91다43527).

⑦ 해제의 소급효 = 물권적 효과설 — 원상회복청구권의 성질C-23b · 75다1394 · 80다2968 · 11회 선택

✓ 계약이 해제되면 이행으로 변동된 물권은 등기·인도 없이 당연히 원상 복귀한다 — "우리 법제가 물권행위의 독자성·무인성을 인정하지 않는 점과 §548① 단서가 거래안전을 위한 특별규정인 점"(75다1394) → 직접효과설 중 물권적 효과설. ✓ 그 결과 원상회복청구권은 소유권에 기한 물권적 청구권 → 소멸시효 대상이 아니다(80다2968, 표준판례173, 11회 선택). 청산관계설이면 채권적 청구권으로 10년 시효(§162①). ✓ 물권적 청구권 보전을 위한 가등기는 불가. 다만 "해제되면 매수인이 매도인에게 이전등기해 주기로 한 약정"이 있으면 그 청구권은 채권적이어서 가등기로 보전 가능(81다카1110, 표준판례629).

⑧ §548① 단서의 제3자 — 대금채권 양수인은 보호 안 됨C-23c · 2000다22850 · 3·6회 선택

✓ 원상회복의무(§548①)는 이익의 현존 여부·선악을 불문하고 받은 급부 전체를 반환하는 것으로, §748의 특칙이다(98다43175). ✓ 사안: A가 B에게 분양 → A가 대금채권을 C에게 양도·통지 → C가 B로부터 대금 일부 수령 → A의 이행불능으로 분양계약 해제. 이때 C는 ⓐ §548① 단서의 제3자로 보호되지 않고, ⓑ §451② 반대해석으로도 보호되지 않으며(해제권 발생의 기초가 되는 계약이 통지 전 이미 성립했으므로 "통지 받기 전에 생긴 사유"), ⓒ A의 동시이행항변권(§549)을 원용할 수도 없어 → 받은 분양대금을 B에게 반환해야 한다(2000다22850, 3·6회 선택). ✗ "양수인도 제3자로 보호"라고 처리하면 오답.

⑨ 타인권리매매 — §569·§570 담보책임C-36a · 93다20283 · 12회 선택

✓ 타인권리 매매도 유효하며(§569), 원시적·주관적 불능이라도 당연무효가 아니다(93다20283, 12회 선택). 매도인은 권리를 취득해 이전할 의무를 지고, 이전 불능이면 매수인은 계약해제 가능. 다만 계약 당시 타인 소유임을 안 매수인은 손해배상 청구 불가(§570 단서). ✓ "권리가 타인에게 속하는지"는 법률적·실질적으로 판단: ⓐ 부동산 미등기전매는 성립요건주의상 타인권리매매(81다528) ⓑ 매도인의 취득원인이 무효여서 매수인이 추탈당한 경우도 타인권리매매(80다2750) ⓒ 그러나 유효한 명의신탁의 신탁자는 사실상·법률상 처분권원에 의해 매도한 것이므로 타인권리매매가 아니다(96다18656, 6회 선택).

⑩ 수량을 지정한 매매 — §574 대금감액C-36c · 99다58136 · 2002다65189

✓ "수량을 지정한 매매" = 당사자가 목적물이 일정 수량을 가진다는 데 주안을 두고 대금도 그 수량을 기준으로 정한 경우. 부족·일부멸실을 매수인이 알지 못한 때 §572·§573이 준용된다(§574). ✓ [긍정] 공유대지면적을 지정한 아파트 분양계약 → 수량지정매매, 면적 부족 시 §574 대금감액청구권 인정(99다58136, 6회 선택) / 건물 일부 임대차에서 면적 수량을 기초로 보증금·월임료를 정한 경우 수량을 지정한 임대차(94다38342). ✓ [부정] 등기부 면적 표시는 통상 특정을 위한 방편에 불과 / 평당가격을 곱해 대금을 정했더라도 대금 결정의 방편이면 아님(92다56674) / 임의경매에서 감정인이 단위면적당 가액×공부상 면적으로 산정해도 수량지정매매 아님(2002다65189, 9회 선택). 단 일정 면적을 중요 요소로 삼아 가격을 정했다면 평당가 기재가 없어도 수량지정매매(95다48780).

⑪ 주택임대차 대항력 — §3① 인도+주민등록, 존속요건C-47a2 · 전합2004다26133 · 9회 선택

✓ 적용범위: 주거용 건물의 전부·일부, 일부가 주거 외 용도라도 적용(§2 2문). 반대로 비주거용 건물의 일부를 주거로 쓰는 경우는 적용 배제(95다51953). 주거용 여부는 공부상 표시가 아니라 사실상의 실제 용도 기준(94다52522) → 미등기·무허가 건물도 적용대상(전합2004다26133, 9회 선택). 등기하지 않은 전세계약에도 준용(§12). 소유자가 아니어도 적법하게 임대차계약을 체결할 권한이 있는 자와의 계약이면 적용(2011다45689, 4·10회 선택). ✓ 요건: 주택의 인도 + 주민등록, 전입신고 시 주민등록된 것으로 본다(§3① 2문). 적법·유효한 전대 시에도 임차인은 간접점유로 인도 상태 유지(2005다64255). ✓ 존속요건: 인도·주민등록은 취득 시에만이 아니라 계속 존속하는 한도에서만 대항력이 유지 → 일시 퇴거 중 저당권이 설정되면 그 저당권자에게 대항 불가. ✓ 기존 채권을 보증금으로 전환했다는 사정만으로 대항력이 부정되지는 않는다(2001다47535).

⑫ 임대인의 동의 있는 전대 — §630 직접청구의 범위C-48b · 2018다200518 · 2006다45459

✓ 동의 있는 전대에서 전차인은 임대인에 대해 직접 의무를 부담하나(§630①), 특별한 규정이 없는 한 직접 권리는 갖지 못한다. ✓ 임대인의 직접 차임청구 시기 = 임대차·전대차의 변제기가 모두 도래한 때, 금액 = 원임대차 차임과 전대차 차임 중 최소한의 것(2018다200518). 전차인은 전대차계약상 항변으로 대항 가능. ✓ 전차인이 임대인에게 직접 지급하면 그 한도에서 두 차임채권이 모두 소멸. 전차인이 임차인(전대인)에게 지급한 경우 §630① 2문상 대항 불가한 범위는 전대차 차임지급시기를 기준으로 그 전에 지급한 것에 한정되고, 변제기 도래 후 지급분으로는 임대인에게 대항 가능(2006다45459). 다만 지급시기 전 지급이라도 임대인의 청구 전에 지급시기가 도래했다면 대항 가능(2018다200518).
