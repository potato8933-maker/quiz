## 1-2. 소의 적법성 — 대상적격·피고적격·제소기간 (12점) → 예상 약 8점

**① 논점**
- 대상적격 / 피고적격 / 제소기간 3요건 모두 목차화 ✓

**② 법조문·판례**
- 대상적격: 처분 정의(행정소송법 §2①1호, §19) ✓ / **처분성 판단기준 판례(대판 2010. 11. 18. 2008두167 전합) 미인용** △
- 피고적격: §13① ✓ / 수임기관 피고 법리 ✓ (대판 94누1197 미인용)
- 제소기간: §20① ✓

**③ 논리구조**
- 각 요건 일반론 → 사안 적용 구조 ✓

**④ 포섭·분량 【최우선】**
- 대상적격 포섭 양호: 한전=공법인(한국전력공사법), 방송법 §67② 징수업무 수탁 → 행정청 ✓. 다만 처분을 "수신료 징수"로 반복 → '부과처분'으로 표현 교정.
- 피고적격 포섭 양호: "대외적으로 그의 명의로 처분을 한 수임 기관이 피고" ✓
- **✗ 제소기간 계산 오류(핵심 감점):**
  - ✗ 내 서술: "2026. 3. 9. … 90일 이내 … 2026. **7. 8.**까지 (7.7. 공휴일)"
  - ✓ 정답: "2026. 3. 5.자 처분 송달일인 **2026. 3. 9.**을 기준으로 … 그로부터 90일이 되는 날인 **2026. 6. 7.은 일요일**이므로 그 다음날인 **2026. 6. 8.**이 최종 만료일 … 원고는 2026. 6. 8. 이 사건 소를 제기하였으므로 제소기간을 준수"
  - 3. 9. + 90일 = **6. 7.**(일) → 만료 **6. 8.** 인데, 답안은 한 달 뒤(7. 8.)로 오산. 두 처분 중 **먼저 만료되는 3. 5.자 처분(송달 3. 9.)**을 기준으로 계산해야 함.

**⑤ 예상 점수(소계)**: 대상적격 3 / 피고적격 3 / 제소기간 2 = **8 / 12**

**⑦ 오류원인 진단**
- 유형: 조문 미숙형(날짜 계산) + 요건 혼동형(부과 vs 징수)
- 진단: 소송요건 법리·포섭은 갖췄으나 제소기간 산정에서 90일 만료일을 한 달 오산 → 소제기일(⑥)까지 연쇄 오류.
- 개선 방향: 제소기간은 '가장 먼저 만료되는 처분'의 송달일 + 90일 → 말일 공휴일이면 익일로 확정하는 순서를 도식화해 검산할 것.

**③ 논리구조**

  - 방송법 시행령 §43이 §3①'특별한 규정' 아니라는 포섭(답안 '가' 후단)은 방향 맞음 ✓.

**③ 논리구조**

- ✓ 정답 문구: "'군 영내'에 있는 수상기는 그 사용 목적과는 관계없이 등록의무가 면제되는 수상기로서 이에 대하여는 수신료를 부과할 수 없다."
- 보강: 앞머리에 "조세나 부과금 등의 부담금에 관한 법률의 해석 … 법문대로 해석 … 확장·유추해석 허용되지 않는다(대판 2022다218585)"와 "특별부담금" 성질을 명시하면 만점권.

**⑦ 오류원인 진단**
- 유형: 조문 미숙형(호수) + 판례 미숙형
- 진단: 핵심 해석구조는 정확히 포섭했으나 근거 호수(12·13호)와 지도판례를 부정확하게 처리.
- 개선 방향: 시행령 각호 대비 논증 시 호수를 원문과 대조 확인, 부담금 해석 판례를 두괄식으로 배치.
