# 자동 작업 체크포인트 (작업현황.md)

> 이 파일은 예약 작업(자동 실행)의 유일한 진행 상황 기록입니다.
> 매 실행 시: ① 이 파일을 읽고 → ② 최우선 미완 항목을 한 배치만 작업 → ③ 이 파일을 갱신합니다.
> **갱신 시 반드시 Write로 전체 재작성** (OneDrive 마운트 파일에 Edit 사용 시 파일 손상 이력 있음).

---

## 실행 규칙 (매 실행 공통)

1. 아래 [작업 목록]에서 상태가 `진행중` 또는 `대기`인 최상위 항목 하나를 선택.
2. 한 실행당 한 배치만 처리 (토큰 한도 고려. 배치 크기는 각 작업 정의 참조).
3. 배치 완료 즉시 이 파일의 해당 항목 진행 상황(마지막 처리 지점)을 갱신하고 [실행 로그]에 한 줄 추가.
4. 산출물은 지정된 폴더에 저장. 스크립트는 `민사 단권화/자동작업/scripts/`에 저장하여 다음 실행에서 재사용.
5. 중간에 중단되더라도 이 파일에 기록된 지점부터 재개하면 됨.
6. 판단이 필요한 불확실 사항은 임의 결정하지 말고 [확인 필요] 섹션에 기록 후 다음 항목으로.

## 작업 목록

### A. 상법 선택형 오답노트 — 회사법 이후 [상태: 진행중]
- 대상: `민사 단권화/상법/2026.03. 이정엽 인사이트 상법 선택형 변시해설_ 1회차 문제풀이 완료.pdf` (438p)
- 범위: p91(회사편 시작)~p438. **배치 크기: 1회 실행당 15~17페이지 (문항당 시각 검증 토큰 소요로 30p→축소, 2026-07-02 결정).**
- **마지막 처리 페이지: p107 완료 (문제 01~11). 다음 배치: p108부터 (다음 헤더 = p108 변시2회, 문제 12번으로 시작. 문제 번호 12부터 연속 부여).**
- 산출물: 부분 파일은 `자동작업/작업파일/상법_오답노트_회사법_partN_문제XX-YY_pAA-BB.docx`로 저장, 전 범위 완료 후 병합하여 `민사 단권화/상법/상법_선택형_오답노트_회사법_[날짜].docx` 생성.
  - part1 완료: `작업파일/상법_오답노트_회사법_part1_문제01-11_p91-107.docx` (문제 01~11, 제1장 통칙 + 제2장 주식회사(설립) 전반부)
- 방법 (스크립트화 완료 — scripts/ 폴더, 아래 사용법 참조):
  1. `segment_problems.py <start> <end> <out.json>` — 페이지별 헤더('변시N회')/해설마커/체크/형광펜 조사.
  2. `extract_problems.py <start> <end_exclusive> <workdir> <문제시작번호>` — 문제 span 분할, 질문영역 이미지(q{ID}_p{페이지}.png) 렌더, problems.json 생성. 체크 후보 = Ink, 비노랑, x1<95, w<45, h<40. 헤더 y ±28 내 체크는 '맞힘 동그라미'로 제외.
  3. 체크→선지 배정: problems.json의 qchecks(y좌표)와 qlines(선지 라인 y) 기하 매칭 + **질문영역 이미지를 Read로 직접 확인하여 검증** (모호하면 반드시 이미지 확인). '변시'만 나오는 분리 헤더도 이미지에서 회차 확인.
  4. meta.json 수작성: [{"pid","source","topic"(논점명 직접 부여),"chapter"(제3편 회사 > 제N장 ...),"checked"("② · ③")}]
  5. `build_docx.py <workdir> <out.docx> <부제>` — 해설 이미지 자동 렌더(라인 경계 580pt 청크 분할) + docx 조립 (총칙·상행위 완성본과 동일 서식: 맑은 고딕, 장바 1A237E 흰글씨, 논점 0D47A1, 체크선지 C62828, 해설라벨 E65100/FFF8E1, 여백 600DXA, 이미지폭 6667500EMU).
- **방법 변경 (2026-07-02)**: 해설은 체크 선지 블록 선별 대신 **전체 수록**으로 통일 — OCR 마커 매칭이 불안정하여(마커 수 불일치 빈번) 잘못된 블록 선별 위험 회피. 내용 손실 없음, 분량만 다소 증가.
- 필기 규칙: 선지 번호 왼쪽 체크(✓/X/별표, 검정+빨강)=틀림/헷갈림. 선지 오른쪽 O/X=풀이 흔적(무시). 문제번호 위 동그라미=맞힘(무시). 형광펜=수록.

### B. 상법 쟁점별 비교 오답노트 — 회사법 [상태: 대기, A 완료 후]
- A에서 수집한 체크 선지를 쟁점 클러스터로 재편성. 각 클러스터 = 비교표(올바른 명제로 통일 + O + 출처 문제번호) + 구별 포인트.
- 산출물: `민사 단권화/상법/상법_쟁점별_비교_오답노트_회사법_[날짜].docx`
- 총칙·상행위 완성본(`상법_쟁점별_비교_오답노트_총칙·상행위_2026-06-11.docx`)과 동일 포맷.
- 참고: A의 각 배치 meta.json(작업파일/회사법_batchN/)에 논점명·체크선지가 축적되므로 이를 활용.

### C. 논점 DB 구축 (기존 찌라시 → 구조화 DB) [상태: 대기]
- 대상: `민사 단권화/민소/`, `민사 단권화/민법/`의 날짜별 찌라시·암기노트 docx 전체. **배치 크기: 1회 실행당 5개 파일.**
- 처리 완료 파일 목록: (없음)
- 산출물: `민사 단권화/자동작업/논점DB.json` + `민사 단권화/자동작업/논점DB.xlsx`
- 스키마(항목당): 과목(민소/민법/상법), 논점명, 편/장 경로, 두문자, 판례 문구 원문(" " 그대로, 축약 금지), <키워드>, 출처 파일명, 수록 날짜
- 주의: 판례 문구는 한 글자도 변경 금지. 동일 논점 중복 시 병합하되 출처·날짜는 모두 누적.

- 대상: `민사 단권화/민법/2026.01. 윤동환 민법의 맥 .pdf`

- 용도: 민법 암기노트 생성 시 쟁점 경로 분류 자동화. **1~2회 실행으로 완료 가능.**

## 스크립트 사용법 (scripts/)

- `survey_annots.py 91 120 > out.json` — 페이지 범위 필기 조사 (체크 후보/형광펜 수, 문제 헤더).
- `segment_problems.py 91 122 out.json` — 세그먼트 상세 (헤더·마커·체크·장제목 y좌표).
- `extract_problems.py 92 107 <workdir> 1` — 문제 추출 + 질문 이미지 렌더. workdir에 problems.json 생성. 4번째 인자 = 시작 문제번호.
- `build_docx.py <workdir> <out.docx> "부제"` — meta.json(수작성 필요) + problems.json → 해설 렌더 + docx 저장.
- 의존성: pymupdf, python-docx, pillow (pip install --break-system-packages).
- 이미지를 Read로 보려면 outputs 폴더(/sessions/.../mnt/outputs/)로 cp 후 Windows 경로로 Read.
