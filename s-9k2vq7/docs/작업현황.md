# 자동 작업 체크포인트 (작업현황.md)

> 이 파일은 예약 작업(자동 실행)의 유일한 진행 상황 기록입니다.
> 매 실행 시: ① 이 파일을 읽고 → ② 최우선 미완 항목을 한 배치만 작업 → ③ 이 파일을 갱신합니다.
> **갱신 시 반드시 Write로 전체 재작성** (OneDrive 마운트 파일에 Edit 사용 시 파일 손상 이력 있음).

## 실행 규칙 (매 실행 공통)

1. 아래 [작업 목록]에서 상태가 `진행중` 또는 `대기`인 최상위 항목 하나를 선택.
2. 한 실행당 한 배치만 처리 (토큰 한도 고려. 배치 크기는 각 작업 정의 참조).
3. 배치 완료 즉시 이 파일의 해당 항목 진행 상황(마지막 처리 지점)을 갱신하고 [실행 로그]에 한 줄 추가.
4. 산출물은 지정된 폴더에 저장. 스크립트는 `민사 단권화/자동작업/scripts/`에 저장하여 다음 실행에서 재사용.
5. 중간에 중단되더라도 이 파일에 기록된 지점부터 재개하면 됨.
6. 판단이 필요한 불확실 사항은 임의 결정하지 말고 [확인 필요] 섹션에 기록 후 다음 항목으로.

(배치3~8에서 이 방식으로 전수 시각검증 완료. 문제가 여러 페이지에 걸치면 페이지별 스트립 생성됨 — 해설/선지행만 있는 페이지 스트립은 체크 판정에서 제외)
- 필기 규칙: 선지 번호 왼쪽 체크(✓/슬래시/별표/V, 검정+빨강)=틀림/헷갈림 → 수록. 선지 오른쪽 O/X/?=풀이 흔적(무시). 문제번호 위 동그라미·큰 Ø스크리블·본문 내 원(circle)·본문 취소선·본문 빨간 강조선=중요표시/풀이흔적(무시). 형광펜(노랑)=수록.

## 스크립트 사용법 (scripts/)

- PDF 경로 자동해석: 모든 스크립트가 `scripts/../../상법/*변시해설*.pdf`를 glob으로 찾음 (세션 마운트 경로 변동 무관).
- `survey_annots.py 91 120 > out.json` — 페이지 범위 필기 조사.
- `segment_problems.py 155 172 out.json` — 세그먼트 상세 (헤더·마커·체크·장제목 y좌표). 대용량 PDF지만 open 0.5초, 배치당 수초 내 완료.
- `extract_problems.py 155 171 <workdir> 46` — 문제 추출 + 질문 이미지 렌더. 4번째 인자 = 시작 문제번호. **두 번째 인자 = 헤더를 포함할 마지막 1-index 페이지(그 다음 헤더는 span 경계로만 사용, 문제로는 미생성). 예: 155 171 → p155~p171 헤더 문제만 생성, p172 헤더는 경계.**
- `build_docx.py <workdir> <out.docx> "부제"` — meta.json(수작성) + problems.json → 해설 렌더 + docx. **meta.json의 pid는 문자열이어야 함(problems.json과 일치).**
- 시각검증 스트립: qlines 전체 min/max y 기준(페이지별 그룹핑) `fitz.Rect(30,y0-16,190,y1+45)` zoom6 렌더 → `outputs/strips2/`에 저장 → Read로 확인. **pno는 1-index → `doc[pno-1]`.** 재사용 스크립트: `scripts/render_strips.py <workdir> <out폴더>`. (선지별 y 자동추출은 OCR 기호 왜곡으로 비권장)
- 의존성: `pip install pymupdf python-docx pillow --break-system-packages` (매 세션 재설치 필요).
