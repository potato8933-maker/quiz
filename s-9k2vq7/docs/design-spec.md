## 찌라시 (make_chira.js)

### 레이아웃 원칙
- **2컬럼 필수**: 좌=목차 구조 / 우=해당 목차의 판례·키워드
- **다중 행 테이블 (수직 정렬이 핵심)**: 논점 내 소목차마다 별도 행 분리. 판례가 다른 소목차와 같은 줄에서 시작하면 소속을 오해하기 때문. 판례 없는 소목차의 우측은 빈칸 (억지로 채우지 않음).
- 밀도 목표: 3~4페이지. 자기 전 가볍게 훑는 용도이므로 여백 최소화.

### 폰트·치수 (docx half-point 단위)
- SZ=18(본문 9pt), SZ_S=16(판례·서브 8pt), SZ_H=22(섹션헤더 11pt), SZ_L=19(논점명 9.5pt)
- 폰트: 맑은 고딕. 마진: 상하좌우 650 내외. 컬럼 너비 좌 5300 / 우 5446 (DXA)
- 간격: 논점 간 44~50, 소목차 간 14~22
- ShadingType.CLEAR 사용 (SOLID는 배경색 깨짐)

### 계층 표현
- 논점명: 파란 굵은 텍스트 + 하단 선 (배경 박스 금지)
- 소목차 `[1]`, `(1)`: 볼드 네이비, 들여쓰기 없음
- bullet `· 라벨: 내용` indent 160 / sub `- 내용` indent 360 (SZ_S)
- 판례 박스: 노란 배경 + 좌측 레드 라인(12), 위에 `▷ 소목차명` 레이블
- 두문자 박스: 오렌지 배경 + 좌측 네이비 라인, 논점 헤더 바로 아래

## 암기노트 (make_memo_note.js) — 프로젝트 지침 확정값

민법은 판례 문장 통째 암기가 목표이므로 현출용 문구가 주인공. 쟁점명·경로는 조용하게.

항목 순서 엄수: 경로 → 쟁점명 → 두문자 → 현출용 문구

| 요소 | 스타일 |
|---|---|
| 경로 | 8pt(size 16), #999999, 📌 접두 |
| 쟁점명 | 10pt(size 20), bold, #555555, 하단 가는 회색 선 |
| 두문자 | 14pt(size 28), bold, #E65100, 노란 배경(FFF9C4) + 주황 좌측 굵은 테두리 |
| 현출용 문구 | 11pt(size 22), #111111, 녹색 좌측 테두리(size 10, 2E7D32), indent 240 |
| 판례 인용문('…') | 위와 동일하되 파란 좌측 테두리 + 연파랑 배경(E3F2FD), #0D47A1 |

폰트: 맑은 고딕. 저장: `민사 단권화/민법/MM.DD_민법_암기노트.docx`

(주의: 프로젝트 지침의 "16pt/20pt/28pt/22pt"는 docx 라이브러리 size 값(half-point)으로 해석해 확정된 수치. 실제 포인트는 그 절반.)
