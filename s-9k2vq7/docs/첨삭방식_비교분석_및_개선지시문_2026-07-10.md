# 첨삭 방식 비교 분석 — Fable(9회) vs Opus(10~15회·모의)
2026. 7. 10. | 목적: 모델과 무관하게 재현 가능한 "더 발전된 첨삭"의 요소 추출

## 0. 전제

두 첨삭 모두 동일한 프로젝트 지시문(7단계 고정 형식)과 누적 메모리(3-B, 증거절 생략, 청구취지 무관용 등)를 따르므로 **골격은 동일**합니다. 그 골격 자체가 Opus 첨삭을 거치며 세직님과 함께 다듬어 온 자산이고, Fable 첨삭도 그 위에서 작동했습니다. 따라서 아래 차이는 "모델의 우열"이 아니라 **이번 세션에서 새로 추가된 절차의 유무**가 대부분이며, 절차로 명문화하면 Opus에서도 동일하게 재현됩니다.

## 1. 요소별 비교

| 요소 | Opus 기존 첨삭 (10회 등) | Fable 9회 첨삭 | 평가 |
|---|---|---|---|
| 청구취지 1:1 대조 | ✗/✓ 표, 문언 단위 지적 — 확립됨 | 동일 + 오류마다 ①②③ 번호로 성격 분리 | 동등. 번호 분리는 오답노트 전사 시 편리 |
| 채점 기준 시점 | 해설(출제 당시 법령) 단일 기준 | **현행 법령·판례 이중 기준** — 웹 검증 후 정답처리(이자제한 20%, 2025 전합 시효포기) | Fable 우위. 단, 이번에 세직님이 지시해서 생긴 절차 — 지시문에 넣으면 Opus도 동일 수행 |
| 감점의 기대가능성 조정 | 가족법 미학습 구분(메모리)만 존재 | 미학습 구분 + **수험생 기대불가능 항목(피고별 교차 병합) 감점 완화** 명시 | Fable 우위. 역시 세직님 지시 기원 — 일반 원칙화 가능 |
| 3-B 누락 요소 분해 | **Opus가 창안**한 항목(10회) — 기능 3분류 완성도 높음 | 형식 그대로 승계 | Opus 자산. 유지 |
| 반복 오류 추적 | 【7】에 반복 패턴 기재, 오답노트와 연계 | 동일 + **재범 횟수 카운트**(가집행 5회째) + **회차 간 기억 간섭** 진단(9회에 10회 관할 이식) | Fable 소폭 우위. "간섭" 관점은 신규 — 붙여서 쓸 가치 있음 |
| 오류 원인 진단 | 유형 분류(암기 부족/쟁점 누락 등) | 동일 + **분량 곡선 진단**(청구 1~3 상세/4~6 붕괴 → 운영 문제로 규정) + 작성 전략 처방(취지 전 항 선완성) | Fable 우위. 9회 답안 특성(후반 붕괴)이 드러나게 한 것이므로, 항목화하면 어느 회차든 적용 가능 |
| 문제 지시사항(작성요령) 대조 | 명시 항목 없음 | 작성요령 3항(피고별)·6항(항변 반영) 위반 여부를 직접 인용해 판정 | Fable 우위. 9회 상환이행 누락은 작성요령 6항 위반임을 짚는 것이 학습 효과 큼 |
| 간결성·표 완성도 | 표 설계 매우 압축적, 군더더기 없음 | 유사하나 판정 셀이 다소 김 | Opus 소폭 우위 |
| 출처 표기 | 해설 내 판례만 인용 | 해설 판례 + 현행 판례는 대법원 보도자료 등 외부 출처 확인 | 용도 다름. 구법 회차에서만 외부 검증 필요 |

## 2. 결론 — "더 발전된 첨삭"의 구성 요소

1. **이중 기준 채점**: 해설 기준 판정 → 현행 법령·판례로 보정. 구 기출(특히 1~11회)은 법령 연혁 확인이 필수 절차.
2. **기대가능성 3단 태그**: 오류마다 [수험생 필수] / [상위권 변별] / [기대곤란] 태그 → 감점과 학습 우선순위를 분리. 점수는 깎되 "고칠 가치가 있는 순서"를 알려주는 것이 목적.
3. **운영(시간·분량) 진단**: 청구별 분량 vs 배점 비율 대조 → 붕괴 지점 식별. 법리 오류와 운영 실패를 구분해야 처방이 달라짐.
4. **작성요령 대조 절차화**: 문제의 【작성요령】 각 호를 체크리스트로 만들어 【1】 형식 검토 앞에 배치.
5. **재범 카운터 + 간섭 경고**: 오답노트 §번호와 연결해 몇 회째인지 명시. 유사 쟁점(관할·이율)의 회차 간 혼동을 별도 경고.

## 3. 프로젝트 지시문에 추가할 블록 (복사용)

아래를 프로젝트 지시문 「■ 운용 원칙 요약」 뒤에 붙이면 Opus 첨삭에서도 동일하게 재현됩니다.

```
■ 현행법 이중 기준 채점 (구 기출 필수)
① 세직은 항상 현행 법령·판례로 푼다. 해설과 다르더라도 현행 기준에 맞으면 정답 처리하고 "현행법 정답처리" 표시.
② 알려진 변경 목록(첨삭 전 대조):
   - 이자제한법 최고이율: ~2018.2.7. 25% / 2018.2.8.~2021.7.6. 24% / 2021.7.7.~ 현행 20%
   - 소촉법 이율: ~2015.9.30. 20% / ~2019.5.31. 15% / 2019.6.1.~ 현행 12%
   - 시효완성 후 일부변제·승인: 대판(전) 2025. 7. 24. 2023다240299 — "시효이익 포기 추정" 법리 폐기.
     포기 인정에는 구체적 사정(동기·경위·자발성 등) 종합 판단 필요. 구 해설의 "포기 추정" 전제 지문은 현행 기준으로 교정.
③ 목록 밖 의심 항목은 첨삭 중단 없이 "현행법 확인 필요" 표시 후 세직에게 고지.

■ 기대가능성 태그
각 오류에 [필수]/[변별]/[기대곤란] 태그. 기대곤란(예: 별개 사건 교차 피고별 병합, 초고난도 병합 구조)은
감점을 최소화하고 TOP 3에서 제외. 학습 우선순위는 필수 → 변별 순.

■ 운영 진단 (신규 절차)
【0】에 청구별 분량 비율을 기재하고, 배점 대비 분량 붕괴 구간(골격·한 줄 답안)을 식별.
붕괴가 있으면 원인을 "법리 부족"이 아닌 "시간 배분"으로 구분 진단하고 작성 순서 전략을 처방.

■ 작성요령 대조 (신규 절차)
【1】 형식 검토 첫 행에 문제 【작성요령】 각 호 준수 여부를 판정(예: 피고별 기재, 이유 있는 항변의 청구취지 반영).

■ 재범 카운터
【7】 반복 오류에 오답노트 §번호와 재범 횟수를 명시(예: 가집행 누락 §1-J — 5회째).
유사 쟁점의 회차 간 기억 간섭(예: 10회 관할 서울중앙 ↔ 9회 성남지원)은 별도 경고.
```

## 4. 이번 9회에서 확인된 세직 학습 상태 (참고)

- 현행 판례 업데이트(2025 전합)를 답안에 먼저 반영한 것은 수험생으로서 드문 강점 — 유지.
- 반면 상환이행 문언(동시이행 반영)이 한 답안에서 2건 누락 — 법리보다 "취지 작성 전 3택 판정(선이행/동시이행/무조건)" 루틴 부재가 원인. 오답노트 신규 유형으로 등록 권장.
