# 헌법 최판 — 위헌(불합치 포함)·권한쟁의 모음 (2025.1 ~ 2026.6)

> 출처: 금동흠 「최신 5개년 중요판례 객관식 92선」(26.08) 해설 원문. 결론이 **위헌·헌법불합치·기본권 침해**인 것 + **권한쟁의 전부** + 탄핵·가처분.
> 여기 없는 1.5개년 판례는 전부 **합헌·기각·각하**로 봐도 됨.

## Ⅱ. 권한쟁의 (3건)

### ① 국회 vs 대통령 권한대행 — 마은혁 미임명 (25.2.27. 2025헌라1) → **권한침해 인용** / 지위확인·임명이행 청구 **각하**
- 국회의 재판관 3인 선출권 = **헌재 구성에 관한 독자적·실질적 권한** (대통령 임명권 견제에 그친다 = 틀림)
- 대통령은 자격요건 충족 + 선출절차 하자 없으면 **임명할 헌법상 의무** → 임의 거부·선별 임명 불가. 하자 있을 때만 보류·재선출 요구 가능
- **권한대행(국무총리·국무위원)도 같은 의무**
- 헌재는 부작위의 권한침해 **확인만** 가능 — **이행판결·법적관계 형성 결정은 근거 없음 → 부적법**
- 국회의장은 대표권에 기한 방어적 행위로 청구 가능 → **별도 본회의 의결 불요**

### ② 중앙선관위 vs 감사원 (25.2.27. 2023헌라5) → **권한침해 인용**
- 감사원 직무감찰 = **행정부 내부 통제** → 국회·법원·헌재처럼 독립 헌법기관인 **선관위도 대상 아님**
- 감사원법 24조③(국회·법원·헌재 공무원 제외)을 '열거적'으로 보아 선관위 포함 = **틀림**
- 권한침해 요건(적법요건 단계) = **침해가능성**만 있으면 충족, 실제 침해·위헌 여부는 본안
- 감사결과 확정(25.2.25)으로 심판이익 원칙상 소멸 → **반복위험·헌법적 해명 필요 → 예외적 심판이익 인정**

### ③ 국회의원 vs 소위원회 위원장 등 (25.9.25. 2024헌라7) → **각하**
- 특검후보추천위원 추천권 = **국회의 권한** → 국회의원 개인 **청구인적격 X**
- **국회 소위원회 위원장 = 당사자능력 X** (헌법 62조는 '위원회'만 명시, 소위 권한은 위원회에서 파생 → 위원회 절차 내에서 해결)
