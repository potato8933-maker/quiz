# content.json 스키마

생성 스크립트 2종이 공통으로 읽는 중간 형식. Claude가 추출 텍스트를 이 JSON으로 정리한 뒤 스크립트를 실행한다.

## 공통 규칙
- 판례 문구는 추출 원문 그대로 넣는다 (따옴표 '…' 포함, 한 글자도 수정 금지).
- `< >` 키워드는 텍스트 안에 그대로 두면 스크립트가 자동으로 crimson bold italic 스타일을 입힌다.
- `→` 뒤 두문자 키워드도 텍스트에 그대로 포함.

## 찌라시 모드 (make_chira.js)

```json
{
  "mode": "chira",
  "title": "민사소송법 찌라시",
  "date": "2026-07-02",
  "sections": [
    {
      "header": "Ⅰ. 소취하 · 재소금지",
      "topics": [
        {
          "name": "논점 33. 재소금지 (제267조 2항)",
          "mnemonic": "당.소.권.이  →  당사자동일 · 소송물동일 · 권리보호이익동일",
          "rows": [
            {
              "left": [
                {"t": "sh", "text": "[1] 소취하"},
                {"t": "bullet", "text": "의의: 소의 전부·일부 철회"},
                {"t": "sub", "text": "- 상대방 동의 요건"}
              ],
              "right": []
            },
            {
              "left": [
                {"t": "sh", "text": "[2] 재소금지"},
                {"t": "rqb", "text": "요건: 당.소.권.이"}
              ],
              "right": [
                {"label": "▷ 재소금지 취지", "text": "'판례 문구 원문 그대로…' (두.문.자)"}
              ]
            }
          ]
        }
      ]
    }
  ]
}
```

left 항목 타입: `sh`(소목차 헤더, 볼드 네이비) / `bullet`(`· 라벨: 내용`, indent 160) / `sub`(`- 내용`, indent 360, 작은 폰트) / `rq`(요건 설명, 회색) / `rqb`(요건 강조, 검정 볼드) / `kw`(두문자, → 빨강)

배치 원칙: **소목차마다 별도 row로 분리**하여 판례가 해당 소목차와 수직 정렬되게 한다. 판례 없는 소목차의 right는 빈 배열.

## 암기노트 모드 (make_memo_note.js)

```json
{
  "mode": "memo",
  "title": "민법 암기노트",
  "date": "05.28",
  "items": [
    {
      "path": "채권총론 > 제2장 채무불이행 > 동시이행항변권",
      "topic": "동시이행항변권 (제536조)",
      "mnemonic": "동.대.변.이  →  동일쌍무계약 · 대가적채무 · 변제기 · 이행제공 없음",
      "phrases": [
        {"text": "'동일한 쌍무계약에 기초한… (원문 그대로)'", "quote": true},
        {"text": "요건: 이.가.위.위  효과: 강.가.손.해", "quote": false}
      ]
    }
  ]
}
```

`quote: true` = 판례 인용문('…' 포함) → 파란 좌측 테두리 + 연파랑 배경. `quote: false` = 일반 현출 문구 → 녹색 좌측 테두리. `mnemonic`은 없으면 생략 가능.
