- [행정법·본안·실체] 이 사건 고시 중 옥상간판 금지 부분이 법령보충적 행정규칙으로 유효한지 ✓ / 위임범위 일탈 ✓ / 무효 고시 근거 처분의 위법 ✓

**② 법조문·판례**
- 옥외광고물법 제4조 제1항·제2항 인용 ✓
- **누락 조문**: 시행령 제24조(금지 장소) vs 제25조(표시방법 강화) 대비, 시행령 **제25조 제3항**(강화되는 표시방법의 범위 → 조례 위임), **제25조 제4항**("특정구역 안의 건물 소유자, 업소 또는 타사광고 등이 지나치게 제한되지 않도록 주의"), **부산광역시 조례 제19조 제2항**(강화 가능 사항 4가지) — 채점기준표: "옥외광고물법 제4조제2항, 동법시행령 제25조제3항, 부산광역시 조례 제19조에 따라 … 특정 유형의 광고물을 아예 금지할 수 있는 사항은 포함되지 않음"

- 효과 표현
  - ✗ 내 서술: "수권법령의 내용을 일탈한 위법한 고시입니다."
  - ✓ 원문(예시답안): "위 법령 등의 위임 범위를 명백히 벗어나 법령상 근거 없이 이루어진 것이므로 법규명령으로서의 대외적 구속력을 인정할 수 없고, 결국 이를 근거로 한 이 사건 거부처분은 위법합니다."
  - 채점기준표: "이 사건 고시 중 특정구역에서 옥상간판을 금지하는 부분은 위임범위를 벗어나 **무효**"

**③ 논리구조**
- 법령보충적 행정규칙 해당 → 위임범위 판단 → 무효 → 처분 위법의 흐름은 갖춤 ✓
- 다만 "행정처분은 법률에 위반되어서는 아니 되며…(행정기본법 제8조)"는 채점 요소가 아님. 그 분량을 법령보충적 행정규칙의 개념·요건에 쓰는 편이 배점상 유리함.

**④ 포섭·분량 【최우선】**
- 잘한 점: "허가 또는 신고 기준을 강화할 수 있다고 위임하였을 뿐, 동법 제4조 제1항에서 적용되는 금지사항에 대하여는 전혀 위임하고 있지 아니하므로" → 금지/제한 구분의 핵심은 잡음 ✓
- 버린 사실 → 살릴 포섭
  - 제4조의 **표제 '광고물등의 금지 또는 제한 등'** → ✓ "광고물 등의 '금지'와 금지에 이르지 아니하는 '제한'을 구분하여 규정"
  - 문언 해석 → ✓ "'허가 또는 신고의 기준을 강화'한다는 것은 허가 또는 신고 자체는 가능함을 전제로 하는 것"
  - 내부회의록: 시행령도 "광고물이 전면 금지되는 장소는 제24조에서, 특정구역에서의 옥외광고물의 표시방법에 대한 기준 강화에 관해서는 제25조에" → 법률·시행령 모두 같은 구조라는 체계적 해석 재료를 버림.
  - 조례 제19조 제2항 4개 항목(간판 총수량 / 모양·길이·색깔 / 표시 위치·장소 / 전기 사용 광고물) → 어디에도 '특정 유형 광고물의 전면 금지'가 없다는 포섭.
  - 내부회의록 "이 사건 옥상간판의 규격 등은 법령상 요건을 만족" + 시행령 제15조(옥상간판 규격: 길이 30m·높이 15m 이내) vs 처분서상 규격(정면 18×8m, 좌우 14.4×8m) → 고시 외에는 거부 사유가 없다는 점.
- 분량: 배점 12점(제1문 최대 배점 쟁점) 대비 과소. 6~7문단은 필요함.

**⑤ 예상 점수(소계)**: 법령보충적 행정규칙 개념·요건 1.5 / 위임범위 일탈 3 / 결론(처분 위법) 1 = **5.5 / 12**

**⑥ 단권화 TOP3**
- ⓐ 옥외광고물법 제4조 = ①항 '금지'(시행령 제24조) vs ②항 '허가·신고 기준 강화'(시행령 제25조) → 강화는 허가 가능을 전제
- ⓑ 시행령 제25조 제3항(조례 위임)·제4항(지나친 제한 금지) + 조례 제19조 제2항 4개 항목 → 전면 금지 권한 없음
- ⓒ 위임범위 일탈 고시 → "법규명령으로서의 대외적 구속력을 인정할 수 없고"(무효) → 이를 근거로 한 처분 위법

**⑦ 오류원인 진단**
- 유형: 포섭 부실형 + 요건 혼동형(법령보충적 행정규칙 요건 미서술)
- 진단: 결론 방향은 맞지만 법률 조문 하나로 끝내고, 출제자가 첨부한 시행령 제24·25조·조례 제19조를 체계적 해석에 쓰지 않음.
- 개선 방향: 위임범위 쟁점은 '법률 → 시행령 → 조례 → 고시' 단계별로 각 1문장씩 대조하는 틀을 고정할 것.

## 1-4. 거부처분 — 신뢰보호원칙 위배 (7점) → 예상 3점

**① 논점**

**② 법조문·판례**
- 행정기본법 제12조 제1항 ✓ / 제2항(실권)도 인용
- **✗ 요건 구조 미서술**: 채점기준표 "신뢰보호의 원칙 개념, 요건 등(3)" → 공적 견해표명 / 신뢰에 귀책사유 없음 / 공익·제3자 이익 침해 우려 없음 등 요건을 항목화하지 않음.
- 제12조 제2항(장기간 권한 불행사)은 채점 요소가 아님. 사안은 피고가 권한을 행사하지 않은 경우가 아니라 **연장허가를 적극적으로 해 준** 경우이므로, '공적 견해표명' 요건에 무게를 두어야 함.

**③ 논리구조**
- 요건별 포섭 없이 사실 나열 → "신뢰보호 원칙에 반합니다"로 직행.

**④ 포섭·분량 【최우선】**
- 잘한 점: 2011년 조례, 2013년·2018년 고시 이후에도 수차례 연장허가를 해 주었다는 사실, 사정변경 없음 ✓
- **✗ 사실 오기**: "원고는 2009. 5. 2.부터" → 허가증상 표시기간 "2009년05월11일부터 2012년05월10일까지"(상담일지는 "2009. 5.경")
- 버린 사실 → 살릴 포섭
  - **공적 견해표명으로 연결하는 문장 부재** → ✓ "피고는 위 각 고시의 존재에도 불구하고 원고에 대하여 옥외광고물 표시 연장허가를 그동안 아무런 이의를 유보함이 없이 해주었던바, 이로써 피고는 관계 법령상 위 장소에서 옥상간판의 설치 및 표시허가가 가능하다는 취지의 공적인 견해표명을 한 것으로 볼 수 있습니다."
  - 허가증 5장(2009·2012·2015·2018·2021) → 특정구역 지정(2011. 9. 16.) **이후의 연장 4회**를 날짜로 특정하면 포섭이 구체화됨.
  - 2009년 최초 설치 당시 특정구역 미지정 → 원고의 신뢰에 귀책사유 없음.
  - ✓ "피고가 표시기간 연장허가를 하더라도 이로써 공익 또는 제3자의 정당한 이익을 해할 우려가 있는 경우에 해당하지도 아니합니다." — 미서술.

**⑤ 예상 점수(소계)**: 개념·요건 1 / 공적 견해표명 1 / 신뢰 정당성·공익 1 = **3 / 7**

**⑥ 단권화 TOP3**
- ⓐ 신뢰보호 요건을 항목별로: 공적 견해표명 → 귀책사유 없음 → (신뢰에 기초한 행위) → 반하는 처분 → 공익·제3자 이익 침해 우려 없음
- ⓑ "고시 존재에도 불구하고 이의 유보 없이 연장허가" = 공적 견해표명
- ⓒ 사실관계 날짜는 허가증 등 증거서류 기준으로 인용

**⑦ 오류원인 진단**
- 유형: 요건 혼동형 + 포섭 부실형
- 진단: 유리한 사실은 잘 모았으나 요건(특히 공적 견해표명)에 연결하지 않아 사실 나열에 그침. 실권의 법리를 섞어 쟁점이 흐려짐.
- 개선 방향: 신뢰보호는 "요건 ① … 사안의 경우 …" 식으로 요건마다 사실을 1:1로 붙일 것.

## 1-5. 거부처분 — 재량권 일탈·남용(비례원칙) (7점) → 예상 2.5점

**② 법조문·판례**
- **✗ 법적 성격 오류**
  - ✗ 내 서술: "이사건 허가처분은 설권적 처분으로서 특허에 해당하고, 이 사건 거부처분은 재량행위입니다."
  - ✓ 원문(예시답안): "광고물의 표시허가는 행정법상의 이른바 허가로서 일반적 금지를 특정한 경우에 해제하는 것이고 그 행정행위의 본질상 금지의 해제나 그 해제를 다시 철회하는 것은 공익성과 합목적성에 따른 당해 행정청의 재량행위라 할 것이며, 광고물의 표시기간 연장허가 역시 마찬가지라고 할 것입니다."

**③ 논리구조**
- "사정을 전혀 형량하지 않은" → **형량 누락**으로 구성함. 채점기준표는 "비례의 원칙 사안에의 구체적 적용(5)" → 공익 vs 사익 비교 구조로 써야 함.

**④ 포섭·분량 【최우선】**
- **✗ 사실 오기**: "수억원에 이르는 **철거비용**을 부담" → 기록: "이 사건 옥상간판의 **설치･유지 비용**은 수억 원에 이르는데 아직 그 비용을 전부 회수하지 못한 상태"
- 버린 사실 → 살릴 포섭(상담일지 5항이 통째로 포섭 재료)
  - 비용 **미회수** 상태
  - "크기가 클 뿐 아니라 해운대 해변 중심가와 가깝고 유동인구가 많은 곳" → 광고대행료 고액
  - "다른 광고대행업무의 경우 매출 규모가 소액" → **매출 대부분 의존**
  - "고용된 직원들도 모두 해고될 수밖에 없다"
  - 앞의 법률유보 위반(위임 없는 금지)을 재량 판단의 논거로 다시 끌어오기 → ✓ "① 위에서 살핀 바와 같이, 옥외광고물법이 피고에게 … 옥상간판의 설치 및 표시 허가 자체를 금지할 권한까지 위임하였다고 볼 수 없는 점"
  - 결론 문장 → ✓ "이 사건 거부처분으로 인하여 실현되는 공익보다는 원고의 사익에 대한 침해가 훨씬 크다고 할 것이므로, 이 사건 거부처분은 명백히 비례원칙에 위배되어 재량권을 일탈하거나 남용한 위법이 있습니다."

**⑤ 예상 점수(소계)**: 법적 성격·재량성 0.5 / 비례원칙 적용 2 = **2.5 / 7**

**⑥ 단권화 TOP3**
- ⓐ 광고물 표시허가 = 허가(일반적 금지의 해제) + 재량행위, 연장허가도 같음 (특허 ✗)
- ⓑ 옥외광고물법 제2조의2(적용상의 주의) → 재량 통제 근거로 원용
- ⓒ 비례원칙 포섭 = 공익(경관) vs 사익(미회수 비용·매출 의존·직원 해고·폐업) → "사익 침해가 훨씬 크다"

**⑦ 오류원인 진단**
- 유형: 요건 혼동형(허가/특허) + 포섭 부실형
- 진단: 상담일지 5항의 구체적 사실 5~6개 중 1~2개만 쓰고, 그것도 '철거비용'으로 바꿔 씀. 재량 하자 유형을 '형량 누락'으로 잡아 비례 비교가 빠짐.
