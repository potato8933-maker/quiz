# Ⅲ. 청구원인 오류 (누락 / 불필요 / 사실 오류)

## 1. 피고 박강인, 박호균
- **누락**
  - 특약 1항(위약 시 몰수·배액상환)의 성질 → 손해배상액 예정 + 해약금. 원고 답신(2023. 12. 9.)의 "위약금이지 해약금이 아니다"라는 주장을 먼저 판단한 뒤 이행착수로 넘어가야 함
  - 해제통지(12. 7. 발송, 12. 8. 도달)와 배액 공탁(12. 13.) 사실, 그리고 **공탁통지 도달 = 해제 의사표시**라는 점
  - **강채만이 계약 자리에 동석** → 채권양도 통지도 그 자리에서 이루어짐(이행착수 포섭의 핵심 사실)
  - 가압류 결정(2023. 12. 23.)과 제3채무자 송달(12. 27.) 사실
  - 소결: 각 3억 4,500만 원 계산식 {(8억 − 1억 1천만) × 1/2}
- **불필요**: "지급에 갈음 vs 지급을 위하여 추정" 논의. 계약서 특약 2항에 "지급에 갈음하여"라고 명시되어 있고, 어느 쪽이든 이행착수는 인정되므로 채점 대상이 아님
- **형식**: 항 번호 "1." 누락

## 2. 피고 김성수
- **사실 오류**: 청구원인 1)에 "**원고 소유의** 별지목록 제2항 기재 토지"라고 씀 → 기록 19쪽 등기부에 따르면 **2024. 5. 21. 김효원 명의로 소유권이전등기**가 되어 있음. 원고는 **종전 소유자**이므로 말소청구의 근거를 소유권이 아닌 **근저당권설정계약상 권리**로 구성해야 함(→ Ⅳ-B-3)
- **누락**
  - 원고가 건축자재 판매점 운영자금으로 빌렸으므로 **보조적 상행위** → 5년. 답안은 "상행위를 위하여 차용"이라고만 씀
  - 초일불산입 계산(2018. 4. 6. 기산 → 2023. 4. 5. 완성)
  - 선행소송 항소심에서 소를 취하해 **1심 각하판결도 실효됨**
  - 2024. 2. 1. 문자 독촉은 **시효완성 후의 최고**라서 의미 없음
  - 민법 제369조
- **불필요·부정확**
  - "변제기로부터 5년 후인 2023. 4. 1. 일응 완성" → 승인으로 어차피 다시 계산하므로 불필요함. 계산도 틀림(2023. 3. 31. 만료)
  - "2023. 4. 6. 시효완성" → 2023. 4. 5.
- **순서**: 재소금지(본안전 항변)를 **먼저** 써야 함

### B-10. 집행채권 소멸과 전부명령 — **대법원 1996. 6. 28. 선고 95다45460 판결**
