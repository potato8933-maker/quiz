# 민사법 찌라시·암기노트 생성 스킬

박세직(변호사시험 수험생)의 민사법 학습 자료를 생성한다. 두 가지 산출물이 있다:

| 모드 | 대상 | 형식 | 목적 |
|------|------|------|------|
| 찌라시 | 민소법 (또는 통합) | 2컬럼 테이블 (좌=목차 구조, 우=판례) | 자기 전 빠른 복습 (3~4페이지) |
| 암기노트 | 민법 | 세로 흐름 (경로→쟁점→두문자→현출 문구) | 판례 문장 통째 암기 |

## 절대 원칙 (위반 시 자료 가치 상실)

- `" "` 또는 `‘ ’` 안 판례 문구는 **원문 그대로** 보존. 축약·변형·오탈자 수정 모두 금지. 이 문구는 시험 답안에 그대로 현출하기 위해 암기하는 대상이므로, 한 글자가 달라지면 잘못된 문장을 암기하게 된다.
- `< >` 안 키워드는 `< >` 형식 그대로 유지 (스크립트가 자동으로 강조 스타일 적용).
- 업로드 파일에 없는 내용을 임의로 추가하지 말 것. 입력 자체가 이미 세직이 요약한 완성본이므로 추가 요약·생략도 금지 — 원문 항목을 전부 반영한다.
- 쟁점명이 없으면 민법 조문·목차·법리 키워드로 추론해 부여한다 (민법의 맥 PDF 목차 참조: `민사 단권화/민법/2026.01. 윤동환 민법의 맥 .pdf`, 인덱스가 있으면 `민사 단권화/자동작업/민법의맥_목차인덱스.json` 사용).

## 워크플로우

### 1단계 — 입력 추출
- HWP 파일: `scripts/hwp_extract.py` 실행 (OLE2 파싱, 홀수 정렬 UTF-16LE 추출).
  ```bash
  python3 scripts/hwp_extract.py "입력파일.hwp" > extracted.txt
  ```
  짝수 정렬로 읽으면 깨진 문자(뾿뾿뾿)가 나온다 — 스크립트가 이미 처리하므로 수정하지 말 것.
- txt 파일 또는 채팅 입력: 그대로 사용.

### 2단계 — 구조 파악
추출 텍스트를 읽고 논점 단위로 분해한다: 논점명 / 소목차 / 요건·두문자 / 판례 문구 / 키워드(< >). 원문과 대조하여 누락이 없는지 확인한다. 시험지 양식 잔여물("수험번호", "제  회" 등 앞부분 몇 줄)은 제외.

### 3단계 — 콘텐츠 JSON 작성
`references/content-schema.md`의 스키마에 따라 `content.json`을 작성한다. 판례 문구는 추출 결과에서 복사해 그대로 넣는다 (직접 타이핑 금지 — 오탈자 위험).

### 4단계 — docx 생성
```bash
mkdir -p /tmp/chira && cd /tmp/chira && npm install docx --silent   # 최초 1회
NODE_PATH=/tmp/chira/node_modules node scripts/make_chira.js content.json 출력.docx      # 민소 찌라시
NODE_PATH=/tmp/chira/node_modules node scripts/make_memo_note.js content.json 출력.docx  # 민법 암기노트
```
(NODE_PATH 필수 — 스크립트가 스킬 폴더에 있어 모듈 경로가 분리되어 있음.)
디자인 상수는 스크립트에 고정되어 있다(v5 확정값). 임의 변경 금지 — 세직과 여러 차례 반복하여 확정한 값이다. 상세 근거는 `references/design-spec.md`.

### 5단계 — 저장 및 검증
- 찌라시: `민사 단권화/민소/YYYY-MM-DD_민소_찌라시.docx`
- 암기노트: `민사 단권화/민법/MM.DD_민법_암기노트.docx`
- 생성 후 document.xml에서 텍스트를 추출해 판례 문구가 입력 원문과 한 글자도 다르지 않은지 프로그램으로 대조한다:
  ```bash
  unzip -p 출력.docx word/document.xml | python3 -c "import sys,re; t=''.join(re.findall(r'<w:t[^>]*>([^<]*)</w:t>', sys.stdin.read())); print('원문 문구' in t)"
  ```
- OneDrive 마운트 파일에는 Edit 도구를 쓰지 말 것 (파일 손상 이력). 수정은 새 파일 Write.
