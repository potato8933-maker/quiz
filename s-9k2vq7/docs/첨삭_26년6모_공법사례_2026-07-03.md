## 1-1. 재판의 전제성 요건 충족 여부 (15점) → 예상 6점

**① 논점**
- 재판 전제성 3요건(계속성/적용성/다른 내용의 재판) ✓ 서술
- **【핵심 누락 ✗】 4개 조문(성폭법 §30⑥, §42①, 청소년성보호법 §21②, §56①)을 개별적으로 나누어 전제성을 판단해야 하는 것이 이 문항의 출제의도인데, 답안은 "문제되는 법률"을 단수·일체로만 처리함.** 특히 §42①(신상정보 등록)의 전제성 부정이라는 득점 포인트를 완전히 놓침.
- 헌마/헌바 구분: §68②(위헌심사형) 정확히 특정 ✓

**② 법조문·판례**
- 헌재법 §68② 인용 ✓ / **§75⑧(인용 시 재심청구 근거) 누락 ✗**
- 조문 개별 적시(§42①, §21②, §56①) 전부 누락 ✗

**③ 논리구조**
- 일반론 → 요건별 검토 → 결론 순서 자체는 정상. 그러나 Ⅱ·Ⅲ이 조문별로 갈라지지 않아 채점표의 배점 구조(적용성 4점·다른 내용의 재판 4점)와 맞물리지 못함.

**④ 포섭·분량 【최우선】**
- **버린 사실 → 살릴 포섭:**
  - ✗ 내 서술: "문제되는 법률이 형사재판에 갑에 대한 처벌의 근거로써 적용되었으므로" (조문 뭉뚱그림)
  - ✓ 정답 방향(적용성): "당해 사건에서 성폭력처벌법 제30조 제6항이 적용되어 원진술자에 대한 증인신문 없이도 영상녹화CD에 수록된 피해자 진술의 증거능력이 인정되었으므로 … 당해사건에 적용되는 법률조항이다."
  - ✓ 정답 방향(§42① 부정): "이는 형사소송인 당해사건에서 형벌의 근거조항으로서 직접 적용되는 조항이 아니라, 당해 사건의 유죄판결이 확정되고 난 후 그 유죄판결에 기초하여 부과되는 새로운 제재의 근거조항이므로, … 당해 형사사건 재판에 적용되는 법률조항이라고 볼 수 없다."
- 문제지가 4개 조문을 준 것 자체가 "조문별로 결론을 달리하라"는 신호였음. 사실(각 조문의 성격)을 포섭 재료로 전혀 활용하지 못함.

**⑤ 예상 점수**
- 쟁점 1 / 법리 3 / 포섭 1 / 결론 1 = **6 / 15**

**⑥ 단권화 TOP3**
- ⓐ §68② 전제성은 **조문마다 개별 판단** — 특히 유죄확정 후 부과되는 제재(신상정보 등록 §42①)는 당해 형사재판에 적용되는 조항이 아님 → 전제성 부정
- ⓑ 확정 사건이라도 §75⑧ 재심청구 가능 → 계속성·다른 내용의 재판 인정
- ⓒ "다른 내용의 재판" = 주문뿐 아니라 "재판의 내용과 효력에 관한 법률적 의미가 달라지는 경우"도 포함

**⑦ 오류원인 진단**
- 유형: 논점 누락형 + 포섭 부실형
- 진단: 출제자가 조문을 4개로 나눠 준 의도를 읽지 못하고 "법률"을 하나로 취급하여, 개별 조문 포섭·차등 결론이라는 핵심 배점을 통째로 상실함.
- 개선 방향: 문제에 여러 조문이 나열되면 반드시 조문별 목차(가·나·다·라)를 세워 각각 포섭·결론을 낼 것.

  - ✓ "증인의 채택 여부는 법원의 재량에 맡겨져 있고 … 피해자가 법정에 반드시 출석하리라는 보장이 없어 … 반대신문권 행사가 충실히 제도적으로 보장되고 있다고 보기는 어렵다."

**⑤ 예상 점수**

- 개선 방향: 배점 큰 요건(침해최소성)은 독립 목차로 두고 최소 3개 논거를 사안 사실과 붙여 쓸 것.

## 1-3. 공권력 행사성 및 직접성 요건 충족 여부 (15점) → 예상 9점

**① 논점**
- 공권력 행사성 + 직접성 ✓
- **✗ 결론 오류: "직접성은 없다"** → ✓ 정답: **직접성 인정.**

**② 법조문·판례**
- 공법인·대외적 구속력 논증 방향 ✓ / 변협 근거판례(헌재 2017헌마759) 미인용
- 직접성 판단에서 **변호사법 §23②7호·§23④ 위임 조문 미적시 ✗**

**③ 논리구조**
- 공권력 행사성 일반론 → 검토 순서 ✓

**④ 포섭·분량 【최우선】**
- 공권력 행사성 포섭 양호: "대한변호사협회 규정은 변호사에 대하여 위반시 징계가 이루어지는 등의 구속력이 있으므로" ✓
- **✗ 직접성 포섭 오류:** 답안은 "협회의 유권해석이라는 별도의 절차를 필연적으로 요하므로 직접성 없음"으로 결론. 그러나 채점표는:
  - ✓ "이 사건 규정은 제23조 제2항 제7호 및 같은 조 제4항의 명시적인 위임에 따라 금지되는 변호사 광고의 내용을 규정하고 있으므로, 집행행위에 의하지 아니하고 법령 그 자체에 의하여 자유의 제한이 발생하고 있다. 따라서 이 사건 규정은 기본권 침해의 직접성이 인정된다."
  - ※ '유권해석의 불명확성'은 뒤 문항(법률유보 위반)의 논거이지 직접성 부정 논거가 아님 → **쟁점 혼동.**

**⑤ 예상 점수**
- 공권력 행사성 8 / 직접성(결론오류) 1 = **9 / 15**

**⑥ 단권화 TOP3**
- ⓐ 변협 규정 = 법규명령 아니어도 상위법령(변호사법)과 결합해 대외적 구속력 → 공권력 행사 O
- ⓑ 직접성: **위임에 따라 법령 자체로 자유제한 발생 → 직접성 인정** (집행행위 매개 없음)
- ⓒ '유권해석 불명확'은 법률유보 위반 논거, 직접성 논거로 끌어오면 쟁점 혼동

**⑦ 오류원인 진단**
- 유형: 요건 혼동형 + 논점(결론) 오류형
- 진단: 후행 문항(법률유보)의 논거를 직접성에 앞당겨 써 직접성을 부정하는 정반대 결론에 이름.
- 개선 방향: 직접성은 "집행행위 매개 유무"만으로 판단하고, 규정 내용의 불명확성 논의는 본안(법률유보)으로 미룰 것.

## 1-4. 법률유보원칙 위배 여부 (15점) → 예상 5점

**① 논점**
- 법률유보 위반 여부 ✓
- **✗ 결론 오류: "위배되지 않는다"** → ✓ 정답: **법률유보원칙에 위배됨.**

**② 법조문·판례**
- **✗ 조문 오류: "변호사법 제23조 제1항 제7호"** → ✓ 정답: **제23조 제2항 제7호, 제23조 제4항.**
- 법률유보 일반론(법률에 근거한 규율) 인용 ✓ / 헌재 2021헌마619 미인용

**③ 논리구조**
- 일반론 → 근거 유무 → 위임한계 순서는 잡았으나, 결론이 반대라 전체 포섭이 어긋남.

**④ 포섭·분량 【최우선】**
- **✗ 대상 규정 오독:** 답안은 "공정한 수임을 저해하거나 소비자에게 피해를 줄 우려가 있는 광고"를 이 사건 규정으로 서술. 그러나 '이 사건 규정'은 **'협회의 유권해석에 반하는 내용의 광고'** 부분임 → 심판대상 자체를 잘못 잡음.
  - ✓ 정답 포섭: "이 사건 규정은 단순히 '협회의 유권해석에 위반되는'이라는 표지만을 두고 그에 따라 금지되는 광고의 내용 또는 방법 등을 한정하지 않고 있다. … 수범자들은 유권해석이 내려지기 전까지는 금지되는 내용이 무엇인지 도저히 알 수 없다. … 따라서 이 사건 규정은 수권법률로부터 위임된 범위를 벗어나는 규율 내용까지 포함할 가능성이 있으므로 … 법률유보원칙에 위배된다."

**⑤ 예상 점수**
- 일반론 4 / 포섭·결론 1 = **5 / 15**

**⑥ 단권화 TOP3**
- ⓐ 심판대상('이 사건 규정')을 정확히 특정: **'협회의 유권해석에 반하는 내용의 광고' 부분**
- ⓑ 위임한계 일탈 킬러 포섭: 유권해석 전에는 금지 내용을 예측 불가 → 예측가능성 현저히 저하 → 위임범위 일탈
- ⓒ 위임 근거조문 = 변호사법 **§23②7호·§23④**

**⑦ 오류원인 진단**
- 유형: 논점(심판대상) 오독형 + 조문 미숙형
- 진단: 심판대상 규정을 다른 조항으로 오인해 정반대 결론(적법)에 도달, 이 문항 배점의 대부분을 상실.
- 개선 방향: 문제에서 '(이하 …라 한다)'로 특정한 심판대상 문구를 답안 첫 줄에 그대로 옮겨 적고 시작할 것.

- **✗ 논거 오류:** "군인과 국가는 대등 당사자가 아니고 특수권력관계"라는 서술은 채점표 논리와 다르고 법리적으로 부정확(당사자소송 부적법의 근거는 특수권력관계가 아님).

**③ 논리구조**
- 결론 → 논거 순서 ✓ (기록형이 아닌 사례형이므로 결론 선행도 무방)

**④ 포섭·분량 【최우선】**
- **버린 사실 → 살릴 포섭:** 채점표의 핵심은 '권리 발생 구조':
  - ✓ "급여를 받을 권리는 법령의 규정에 따라 직접 발생하는 것이 아니라 … 국방부장관 등이 지급결정을 함으로써 구체적인 권리가 발생함"
  - ✓ "먼저 … 거부하는 급여지급결정을 하는 경우 그 결정을 대상으로 항고소송을 제기하는 등으로 구체적 권리를 인정받은 다음 비로소 당사자소송으로 그 급여의 지급을 구해야 함. 이러한 구체적인 권리가 발생하지 않은 상태에서 곧바로 … 당사자소송으로 … 소구하는 것은 허용되지 않음"
- 지급청구·거부라는 사안 사실을 '지급결정으로 비로소 권리 발생 → 항고소송 선행' 구조로 포섭했어야 함.

**⑤ 예상 점수**
- 구별 기준 3 / 포섭 2 / 결론 2 = **7 / 15**

**⑥ 단권화 TOP3**
- ⓐ 사망보상금 = **지급결정으로 비로소 구체적 권리 발생** → 거부처분 항고소송 선행, 곧바로 당사자소송 불가(2019두45944)
- ⓑ 당사자소송 vs 항고소송 구별: 권리가 법령상 바로 확정 → 당사자소송 / 결정으로 창설·확정 → 항고소송
- ⓒ '특수권력관계' 논거는 지양 — 권리발생 구조로 포섭할 것

**⑦ 오류원인 진단**
- 유형: 판례 미숙형 + 포섭 부실형
- 진단: 결론은 맞았으나 근거를 특수권력관계로 잘못 잡고 권리발생 구조·판례를 놓쳐 배점의 절반만 확보.
- 개선 방향: 금전급부 소송은 '권리가 법령상 바로 확정되는가, 결정으로 창설되는가'를 판단 축으로 고정할 것.

## 2-5(1). 포괄위임금지원칙 위배 여부 (15점) → 예상 9점

**① 논점**
- 감액비율의 대통령령 위임 → 포괄위임금지 위배 여부 ✓
- 결론(위반)은 채점표상 부정설에 해당 → 논증 설득력 있으면 인정되는 결론 ✓

**② 법조문·판례**
- 헌법 §75 인용 ✓ / 헌재 93헌바32 등 미인용 △

**③ 논리구조**
- 의의 → 예측가능성 → 위임필요성 → 사안 순서 ✓

**④ 포섭·분량 【최우선】**
- **✗ 사실 포섭 오류:** 답안은 "최소한 범위나 상한선조차 정하지 아니하였으므로"라고 서술. 그러나 이 사건 조항은 채점표상 **상한을 규정**하고 있음:
  - ✓ "감액 비율 또한 법률에서 직접 이미 납부한 기여금 총액에 민법상 이자를 가산한 금액 이하로는 감액할 수 없다고 규정하고 있다."(긍정설)
  - 부정설로 가더라도 이 사실을 인정한 뒤 "그 외 감액비율 결정 기준이 전혀 없다"로 논증해야 함. 상한 부존재라는 사실오인은 감점.
- 위임필요성 포섭이 사안에 밀착되지 않고 일반론에 머묾(전문성·정책적 필요 등 미포섭).

**⑤ 예상 점수**
- 쟁점 1 / 일반론 2 / 필요성·예측가능성 4 / 포섭·결론 2 = **9 / 15**

**⑥ 단권화 TOP3**
- ⓐ 이 사건 조항은 **감액사유를 한정**(재직 중 금고이상형 확정·파면·금품수수 해임)하고 **상한**(기여금+민법상 이자)까지 규정 → 긍정설의 예측가능성 근거
- ⓑ 부정설 논거: 감액비율 산정 시 죄질·직무관련성·재직기간 등 반영 정도를 전혀 예측 불가
- ⓒ 예측가능성은 당해 조항 하나가 아니라 관련조항 전체를 유기적·체계적으로 판단

**⑦ 오류원인 진단**
- 유형: 포섭 부실형(사실오인)
- 진단: 결론 방향은 무방하나 조문이 정한 '상한'을 없다고 오인해 포섭의 정확성이 떨어짐.
- 개선 방향: 위임조항 포섭 시 '감액사유 한정 + 상한 규정' 여부를 먼저 확인하고 그 위에서 예측가능성을 논할 것.

## 2-5(2). 소급입법금지원칙 위배 여부 (15점) → 예상 5점

**① 논점**
- 부칙조항의 소급적용 → 헌법 §13② 소급입법금지 위배 여부 ✓
- **✗ 대상 오독:** 문제의 '이 사건 부칙조항'은 **부칙 §1 단서 및 §2① 후단을 묶은 하나의 대상**인데, 답안은 "부칙 1조=위반, 2조=위반 아님"으로 분리해 상반된 결론을 냄. → ✓ 정답: 부칙조항 전체가 **이미 수령한 2025년분에 소급 적용되는 진정소급입법.**

**② 법조문·판례**
- 헌법 §13②·§23① 인용 방향 ✓ (단 "재산구너을" 등 오타 다수)
- **✗ 헌재 97헌바76(진정소급 원칙 금지 + 예외 4유형) 미인용.**

**③ 논리구조**
- **✗ 결론 미완성:** Ⅲ·Ⅳ 목차만 두고 본문 공란 → 최종 결론 부재. 공법은 결론(위헌/합헌, 위배/합치) 미기재 시 감점.

**④ 포섭·분량 【최우선】**
- 진정/부진정 구분 자체는 시도 ✓, 그러나 부칙조항을 통합 진정소급으로 포섭하지 못함.
- **버린 사실 → 살릴 포섭:** 예외사유(중대공익) 형량이 전무:
  - ✓ "이 사건 부칙조항에 따라 이룰 수 있는 공익은 공무원연금공단의 재정 보전이라는 금전적·재정적인 이익으로 한정 … 보전되는 공무원연금의 재정규모도 그리 크지 않을 것 … 국민이 이를 미리 예상하기 어렵고 … 예외사유가 존재한다고 보기도 어렵다."
  - ✓ 결론: "헌법 제13조 제2항에서 금지하는 소급입법에 해당하고, 예외적으로 소급입법이 허용되는 경우에도 해당하지 아니하므로 … 소급입법금지원칙에 위배된다."

**⑤ 예상 점수**
- 일반론 3 / 진정소급 포섭 2 / 결론(미완) 0 = **5 / 15**

**⑥ 단권화 TOP3**
- ⓐ '이 사건 부칙조항'은 통합하여 판단 → 이미 이행기 도래·수령한 2025년분에 소급 = **진정소급입법**
- ⓑ 진정소급 예외 4유형(97헌바76): 예상가능/신뢰이익 적음/손실 경미/중대공익 → 본 사안은 예외 부정
- ⓒ 예외사유는 '매우 엄격하게' 판단, 예상가능성만으로 정당화 불가

**⑦ 오류원인 진단**
- 유형: 논점(대상) 오독형 + 시간부족(미완성)
- 진단: 부칙조항을 분리해 상반 결론을 내고, 예외 형량·최종 결론을 완성하지 못함.
- 개선 방향: '이 사건 ○○조항'으로 묶인 대상은 하나로 판단하고, 소급입법은 '진정소급 → 예외 4유형 형량 → 결론'을 한 세트로 마무리할 것.
