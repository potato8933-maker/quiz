## A-5. R이 주주가 되는 경로 — 면책력 + 선의취득 두 축 ★★★

**3회 답안**

**정답 — 결론은 같으나 경로가 전혀 다릅니다**
- **판례(주권의 효력발생시기)** "주권은 **상법 소정의 형식을 구비한 문서를 주주에게 교부한 때** 비로소 주권으로서의 효력이 생긴다"
- **[축 1] 주주명부의 면책력** — 명부상 주주에게 권리를 인정하면 **진정한 주주가 아니어도 회사는 면책**된다 ⇒ 2016. 7. 20. 빌딩왕이 **무권리자** 丙에게 한 주권 발행은 **명부상 주주에 대한 발행**이므로 **면책력에 의해 주권으로서의 효력이 인정**된다
- **[축 2] 상359조(수표법 21조 준용)** — **양도인이 무권리자여도 선의로 주권을 교부받으면 적법하게 취득**한다. **악의·중과실의 입증책임은 이를 주장하는 자가 진다** ⇒ **R은 선의취득**
- ⇒ R의 명의개서와 R에 대한 소집통지는 **적법**

**한 문장 암기: 「면책력으로 주권이 되고, 359조로 R이 취득한다」.** 하나만 쓰면 R이 주주가 되는 이유가 설명되지 않습니다.

## A-6. 타인 명의 주식인수 — W가 주주, H는 무권리자 ★★★

**3회 답안 — 앞뒤가 정면 모순**
> ✓ (2.4) "예외적으로 … **회사가 이를 알고 승인한 등의 특별한 사정이 있는 경우에는 출연자가 주주**라고 하였다. 따라서 **W가 주주**이고 … **G가 주주**이다"
> ✗ (3.(3) "차명으로 주식을 인수한 경우에도 판례는 **실질설**의 입장에서 … **회사에 대하여 양도 사실로서 통지할 수 있는 자는 丁이다.** 따라서 丁으로부터 양수받은 **H의 명의개서를 인용하여야 하나, 이를 배척하였는바 명의개서 부당거절**에 해당하고 … 명의개서 없이도 주주권을 행사할 수 있다"

**정답**
- **판례** "원칙적으로 **명의자**를 주식인수인으로 본다. 다만 **명의자와 실제 출자자가 실제 출자자를 주식인수인으로 하기로 약정하고 주식인수계약의 상대방인 회사 등이 알고 이를 승낙하는 등 특별한 사정**이 있는 경우에는 예외적으로 **실제 출자자**가 주식인수인이 된다"
- 사안: 문제지 "**빌딩왕은 주식인수 시 이를 알고 승인하였다**" = 예외의 요건 충족 → **W가 주주**
- ⇒ **W → G 양도는 적법**(명의개서·소집통지 적법) / **H는 무권리자 丁으로부터 양수하여 주식을 취득하지 못하고, 주권 발행 전이므로 선의취득도 불가능** → **H에 대한 명의개서 거절은 정당**

**오류의 원인: 丁의 통지에 확정일자가 있었다는 사실에 끌려갔습니다.** 확정일자는 **정당한 권리자 사이의 우열**을 정하는 장치이고, **무권리자의 통지에는 확정일자가 있어도 아무 효력이 없습니다.**

**용어도 틀렸습니다.** 형식설·실질설은 **주주명부 기재의 효력**에 관한 논의이고, 이 항목은 **명의차용 시 주식인수인의 확정** 문제입니다.

# Ⅳ. 두 회차를 겹쳐 보면 드러나는 축 — 세트로 외울 것

## 1. 결의 하자의 「정도 → 효력 → 다투는 방법」 한 장

```
소집절차·결의방법상 하자
   ↓ 하자의 정도
   ├─ 취소사유 (376조1항)                 ← 2회: R 소집 + 丙 + C = 20%
   │    · 제소권자: 주주·이사·감사
   │    · 제소기간: 결의일부터 2개월
   │    · 성질: 형성의 소
   │    · 선결문제로 주장 불가 → 취소판결 없으면 결의는 확정적으로 유효
   │      ⇒ 2회 제1문 결론: 영업반환청구 기각
   │
   └─ 부존재사유 (380조)                  ← 3회: X 1,500 + 乙 1,500 = 60%
        · 제소권자 제한 없음(확인의 이익 있는 자) — 퇴임이사도 386조1항으로 가능
        · 제소기간 제한 없음
        · 성질: 확인의 소
        · 제3자 간 소송에서 선결문제로 언제든 주장 가능
          ⇒ 3회 제2문: A의 청구 인용 / 제3문: D의 반환청구 인용

판례 경향: 41% 취소 / 59% 부존재 / 소집권자 아닌 자의 소집 = 취소 /
          수개의 하자가 중첩되어도 부존재까지는 인정하지 않는 경향
청구취지 오류: 부존재사유인데 무효확인을 구했다면 → 부존재확인의 의미로 선해(전합)
```

**2회는 왼쪽 가지, 3회는 오른쪽 가지를 물었습니다.** 두 회차를 하나의 표로 묶어 외우십시오.
