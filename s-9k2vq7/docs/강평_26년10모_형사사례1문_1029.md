# 10모 형사법 사례형 제1문 공동강평 정리 (2026.10.29 · 충북대 원현호 교수)

- 자료: 공동강평 녹화본(90분)의 슬라이드 43쪽과 음성 녹취를 정리함 / 정리일 2026-11-15
- 세직 1문 실채점: **59/100** (10/20 첨삭 예상 40)
- 범위: 제1문 문1~문5. 제2문은 11/6 별도 강평
- 표기: ✓ 맞음 · △ 일부만 맞음 · ✗ 누락이거나 결론 반대

## 0. 세 줄 요약

1. **강평 결론은 채점기준표와 같습니다.** 세직 답안이 결론을 반대로 쓴 곳은 **문4(국민참여재판)와 문5(비약적 상고)** 두 곳이고, **문3은 출발점(임의제출로 본 것)**이 어긋났습니다.
2. 교수가 반복해서 강조한 점은 다음 네 가지입니다.
   - 법리(판례)를 쓰고 → 사안을 포섭하고 → 결론을 낸다
   - **죄수는 반드시 쓴다**
   - 결론은 **문제가 묻는 형태 그대로** 쓴다
   - 모르는 절차 문제가 나와도 **조문과 결론은 쓰고 넘어간다**
3. 교수가 직접 짐을 덜어 준 부분도 있습니다.
   - **연결효과에 의한 상상적 경합**: "채점한 답안 중에 쓴 사람이 거의 없다. 못 썼다고 자책할 필요 없다."
   - **문4(국참)**: "꽤 지엽적인 내용이다. 시간이 정해져 있다면 이걸 복습하기보다 압수·수색 같은 중요 판례를 더 보라."

## 2. 교수의 답안 작성 Tip (슬라이드와 발언)

1. **업무방해 문제**: 허위사실유포(2009도1721)·위계·위력(2004도8447) 3유형 중 어디에 해당하는지 밝힐 것. 제314조만 쓰고 "위계업무방해 성립"으로 끝낸 답안이 매우 많았음.
2. **죄책 문제의 기본 구조**: 쟁점이 되는 법리(판례)를 쓰고 → 사안을 포섭하고 → 결론을 냄. 법리와 사안을 나눠서 쓰면 답안이 풍성해지고 점수도 높아짐.
3. **한 사람이 여러 죄를 지으면 죄수를 반드시 쓸 것.**
   - 명시적인 판례가 있으면 그에 따름. 예: 사문서위조와 동행사는 실체적 경합, 무면허운전과 음주운전은 상상적 경합.
   - 판례가 없거나 생각이 안 나면 실체적 경합·상상적 경합·포괄일죄의 의의에 비추어 판단.
4. **뇌물 문제는 항상 특가법 적용 여부를 볼 것.**
   - 기준은 수뢰액 3천만 원 이상.
   - 공범 합산과 포괄일죄 합산은 됨. 실체적 경합·상상적 경합 관계의 금액은 합산하지 않음.
   - 제131조 제1항·제2항에는 특가법이 적용됨. 제131조 제3항(퇴직 후 수뢰)과 제133조(공여, 제3자뇌물교부·취득)에는 적용되지 않음.
   - 뇌물수수와 수뢰후부정처사까지 찾아 놓고 특가법을 빠뜨리면 충분한 점수를 받을 수 없음.
5. **증거능력 문제의 결론은 묻는 형태 그대로 쓸 것.** 묻는 형태는 세 가지로 나옴.
   - 유죄의 증거로 쓸 수 있는가(이번 문제)
   - 증거로 쓰기 위한 요건은 무엇인가(10회 변시 2문 4)
   - 증거능력을 부정할 근거를 모두 제시하라(12회 변시 2문 4, 변호인 입장)
6. **모르는 절차 문제, 특히 10점 이하 문제**는 백지를 내지도 말고 시간을 과하게 쓰지도 말 것. 관련 조문(예: 불복 → 항고 → 402·403조)을 인용하고, 틀릴 것 같아도 묻는 것에 대한 결론(예: 항고인지 상소인지)을 쓴 뒤 넘어갈 것. 조문과 결론만으로도 상당 부분 득점할 수 있음.
7. **스스로 쟁점을 만들지 말 것.** 문5의 재소자 특칙처럼 문제가 묻지 않는 부분에 빠지면 시간만 잃음.

## 4. 세직 답안 기준 교정 우선순위 (강평 반영)

1. **문5 비약적 상고**: 항소가 살아 있는 동안 낸 상고는 무효이고, 대법원은 항소심 법원으로 이송합니다(373조, 2025도11655). 재소자 특칙은 **제344조**이고 이 문제의 쟁점이 아닙니다.
2. **문4 국참**: 단독사건은 대상사건이 아니므로 통상절차 진행이 적법합니다. 불복방법은 즉시항고 ✗ → 항고 ✗(403조 1항, 2017모1133) → **상소 ○** 순서로 지워 나가면 됩니다. 전화 통지도 적법합니다(96모94).
3. **문3**: 임의제출이 아니라 **사인을 이용한 강제처분**입니다. 미성년자에게 영장을 제시하고 참여권을 보장해야 하며, 친권자로 대신할 수 없습니다(2022도2071). 결론은 "증거능력 없음"으로 씁니다.
4. **국립대 = 공무원 세트**: 공무상비밀누설(2021도11924) → 위계공무집행방해(2000도4993) → 수뢰후부정처사 포괄일죄와 특가법 순서로 검토하고, 죄수 3단(실체적 경합 / 각각 상상적 경합 / 연결효과)으로 닫습니다.
5. **사립대 丙과 甲**: 丙은 사기(2006도6795)와 배임수재의 상상적 경합, 甲의 丙에 대한 교사는 실패한 교사라 불가벌입니다. 그리고 **인물마다 마지막 줄은 죄수**로 닫습니다.
